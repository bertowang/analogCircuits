§17.1核心概念速览

  • 整流 + 电容滤波：ΔV ≈ Iload/(f·C)；二极管只在峰值附近导通，故导通角小、电流尖峰大。
  • LDO = 基准 + 误差放大器 + 调整管 + 反馈分压；环路增益决定负载调整率，输出电容与 ESR 决定瞬态响应与稳定性。
  • Buck：开关导通时电感储能、关断时经二极管/同步管续流；Vout ≈ D·Vin，效率远高于线性稳压。
  • 功放：A 类线性最好效率最低（理论 25%～50%），B/AB 类有交越失真，D 类用 PWM + LC 滤波换取高效率。
  • 热：结温 = 环境温度 + 功耗 × 热阻；任何电源设计都必须算一次功耗。

§17.2整流纹波的定量估算

二极管只在输入峰值附近导通给电容充电，其余时间电容独自向负载放电：

ΔVpp ≈ Iload/(f·C)（半波），全波桥式约 Iload/(2f·C)

推导只用了 ΔQ = IΔt = CΔV：放电时间约一个周期 1/f。因此减小纹波的三条路：加大 C、提高频率（全波/开关电源）、减小负载电流。

注意两个仿真与实物的差异：二极管只在短时间内导通，充电电流是窄而高的尖峰，会带来 EMI 与变压器利用率问题；电容 ESR 会额外叠加 Ipeak·ESR 的纹波，且决定电容寿命。实验 5-2 的 .tran 波形能同时看到这两点。

§17.3LDO 的环路、调整率与瞬态

LDO 可拆成四块：基准 VREF、误差放大器、调整管、反馈分压。设误差放大器增益 A、分压比 β，则

Vout ≈ VREF/β · Aβ/(1+Aβ)　（Aβ 越大，静态误差越小）

三条常用指标：

  • 线性调整率：输入电压变化引起的输出变化，由环路增益与 PSRR 决定。
  • 负载调整率：负载电流变化引起的输出变化，等于输出阻抗乘以电流变化；实验 17-1 的 0.5 Ω 输出电阻造成的约 10 mV 压降就是它。
  • 负载瞬态：电流阶跃时，先是输出电容 ESR 与容值决定的瞬时下冲，再由环路在有限带宽内把电压拉回；两者时间尺度不同，要分开看。

输出电容的 ESR 还会在环路中引入一个零点：某些老结构需要一定 ESR 才能稳定，换成低 ESR 陶瓷电容反而振荡。这是「照抄应用电路却不能工作」的高频原因。

§17.4DC-DC 与功率放大

Buck 变换器：开关导通时电感储能、关断时经二极管或同步管续流，稳态 Vout ≈ D·Vin（D 为占空比）。电感电流纹波 ΔI ≈ (Vin−Vout)D/(Lfsw)，输出纹波由电容与 ESR 决定。效率远高于线性稳压，代价是开关噪声、EMI 与控制环路更复杂。

功放类别导通角理论效率主要问题
A 类360°25%～50%静态功耗大
B / AB 类180° / 略大于约 70%交越失真（AB 缓解）
D 类开关工作可超 90%PWM 量化噪声、需 LC 滤波

最后一步永远是热：Tj = Ta + Pdiss·RθJA。线性稳压的压差乘电流、功放的损耗、开关管的导通与开关损耗都要算一遍，再决定散热片与封装。

§仿真实验

实验 17-1：LDO 的负载阶跃与调整率

* Ch17 Behavioural LDO: load-step transient and load regulation
VREF ref 0 DC 2.5
BERR err 0 V=V(ref)-V(fb)
E1 eout 0 err 0 100
RO eout out 0.5
R1 out fb 10k
R2 fb 0 10k
COUT out 0 10u
ILOAD out 0 PULSE(0 20m 0 1u 1u 2m 4m)
.tran 0 8m 0 2u
.meas TRAN v_light FIND V(out) AT 1m
.meas TRAN v_heavy FIND V(out) AT 3m
.end

操作：Run → Add Trace → V(out) 与 I(ILOAD)；Error Log 读轻/重载两点电压。　预期与判读：目标 5 V（2.5 V 基准 × 2），有限环路增益 100 带来约 2% 静态误差，实测约 4.90 V；20 mA 负载阶跃经 0.5 Ω 输出电阻再拉低约 10 mV，随后被环路拉回。　文件位置：part2/17-power-supply/sim/17-ldo-load-step.cir

§常见误区

  • 只看稳态输出电压，不看负载阶跃的下冲与恢复时间。
  • LDO 输出电容 ESR 不在稳定性范围内（部分老结构反而需要一定 ESR）。
  • 忽略调整管功耗：压差 × 电流就是热。

  1. 把 E1 增益改成 1000，比较静态误差与瞬态恢复。

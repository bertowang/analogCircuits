§9.1核心概念速览

  • 共源 / 共射：电压增益最大（−gm·RD），输出反相，输入阻抗高、输出阻抗由负载决定。
  • 共漏 / 共集（跟随器）：增益 ≈ 1，但输入阻抗高、输出阻抗低（≈ 1/gm），专职做阻抗变换。
  • 共栅 / 共基：输入阻抗低（≈ 1/gm）、带宽好，常作 cascode 的上管或电流缓冲。
  • 源极 / 发射极退化：加一个电阻引入局部负反馈，增益变成约 −RD/(RS+1/gm)，对器件参数不敏感、线性度变好。
  • 设计顺序恒为：定偏置电流 → 定过驱动电压 → 算 W/L 或电阻 → 校核摆幅与饱和区。

§9.2三种组态的定量推导

把小信号模型代入，三种组态的差别可以一页写完（忽略 ro）：

组态电压增益输入电阻输出电阻
共源 / 共射−gm(RD ∥ RL)∞（MOS）/ rπ（BJT）RD ∥ ro
共漏 / 共集gmRS/(1+gmRS) ≈ 1∞（MOS）(1/gm) ∥ RS
共栅 / 共基+gm(RD ∥ RL)≈ 1/gm高（cascode 后更高）

推导只需两步：在输入回路写 KVL 得到控制电压（如 vgs），在输出节点写 KCL 得到 gmvgs 与负载的关系。任何陌生单级电路都可以这样拆，参见第 19 章。

§9.3偏置设计与摆幅预算

增益算得再漂亮，静态点不对也白搭。设计一只共源级的固定顺序：

  1. 由功耗预算定 ID；由线性度与面积定过驱动 Vov（常取 0.1～0.3 V）。
  2. 由 ID = ½Kp(W/L)Vov² 求 W/L，由 gm = 2ID/Vov 得到跨导。
  3. 由目标增益定 RD，检查直流压降：V(out) = VDD − IDRD。
  4. 摆幅校核：输出最低不能低于 Vov（否则管子进线性区），最高不能超过 VDD；把静态点放在两者中间可得到最大对称摆幅。
  5. 输入共模电平必须让管子导通，并给信号留够余量。

最常见的失败：为了高增益把 RD 取得太大，静态 V(out) 被压到 Vov 以下，管子掉进线性区，增益公式整个失效。先跑一次 .op 再谈增益。

§9.4源极退化：用增益换线性与确定性

源极串 RS 后，栅压变化不会全部落到 vgs 上：

Av ≈ − RD / ( RS + 1/gm )　（gmRS ≫ 1 时 ≈ −RD/RS）

这是局部负反馈：输出电流增大 → RS 上压降增大 → vgs 减小 → 抑制电流。收益是增益几乎只由两个电阻的比决定，对器件参数、温度、工艺不敏感，线性度明显改善；代价是增益下降、噪声略增、消耗一部分电压余量。

把 RS 换成电容或分段旁路，就能在直流稳定与交流增益之间分别取舍——这种「直流负反馈、交流旁路」的手法在第 14 章与第 17 章会反复出现。

§9.5有源负载：把电阻换成电流源

增益 −gmRout 想做大，要么加电流（费功耗、降摆幅），要么提高 Rout。用电流镜作负载可得到 Rout = ron ∥ rop，通常比电阻大一个数量级，于是单级增益可达几十到上百。

代价有三：需要额外的偏置支路、输出摆幅受两管饱和电压挤压、带宽因高阻节点而变窄（该节点的极点变低，见第 12 章）。单级高增益必然伴随高阻节点，这是模拟设计中最基本的取舍之一。

§仿真实验

实验 9-1：源极退化如何把增益交给电阻比

* Ch09 Source degeneration: gain set by resistor ratio
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
VDD vdd 0 DC 5
VIN in 0 DC 2.0 AC 0.05 SINE(2.0 0.05 1k)
RD vdd out 2k
M1 out in src 0 NM1 W=10u L=1u
RS src 0 500
.op
.ac dec 20 100 10Meg
.tran 0 5m 0 2u
.end

操作：Run → Error Log 读 Id 与 V(src)；Add Trace 比较 V(in) 与 V(out) 幅度。　预期与判读：静态 Id ≈ 1 mA（Vsrc = 0.5 V，VGS = 1.5 V）；gm ≈ 2 mS，1/gm = 500 Ω；增益 ≈ −2k/(500+500) = −2，比无退化时的 −3.85 更稳定、更线性。　文件位置：part2/09-single-stage/sim/09-source-degeneration.cir

§常见误区

  • 只算增益不校核 VDS，管子掉进线性区公式全失效。
  • 把跟随器“增益为 1”理解成没用：它的价值是隔离。
  • 忽略 RD 上的直流压降，输出静态点过高或过低导致摆幅不对称。

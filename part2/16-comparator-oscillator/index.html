§16.1核心概念速览

  • 比较器：开环使用、输出饱和、追求速度与低失调；运放：闭环使用、追求线性与稳定，二者不能随便互换。
  • 施密特触发：把输出经分压正反馈到输入，产生两个不同的翻转阈值；迟滞宽度即噪声容限，可消除慢边沿引起的多次翻转。
  • 巴克豪森判据：环路相移 360°（含反相的 180°）且环路增益 ≥ 1 时，微小扰动被放大成等幅振荡；稳态幅度由非线性限幅决定。
  • 三级反相环每级约 60° 相移时总相移达 180°，加上反相本身 180°，满足振荡条件；起振需要一个初始扰动（仿真里用 .ic 或噪声）。

§16.2比较器与迟滞阈值推导

比较器开环使用，输出只有高低两态，虚短完全不适用（第 8 章）。加正反馈分压得到施密特触发器：设输入经 R1、输出经 R2 汇到比较器输入节点 v+，则

v+ = (R2Vin + R1Vout)/(R1+R2)，　β = R1/(R1+R2)

输出为 +VOH 时，翻转条件是 Vin < −βVOH；输出为 −VOL 时，翻转条件是 Vin > βVOL。两个阈值之差就是迟滞宽度，也就是噪声容限：输入上叠加小于该宽度的噪声不会引起误翻转。

慢边沿信号（如温度传感器、机械开关）若不加迟滞，会在阈值附近反复穿越，输出端出现一串毛刺——这是数字系统里最经典的模拟问题之一。

§16.3巴克豪森判据与起振

环路增益 T(jω) = A(jω)β(jω)。持续振荡需要同时满足：

|T(jω0)| ≥ 1　且　∠T(jω0) = 0°（或 360° 的整数倍）
  • 三级反相环：每级反相提供 180°，三级 RC 在 ω0 处再提供 180°，合计 360°，满足相位条件；
  • |T| < 1 时扰动衰减，|T| > 1 时扰动指数增长，最终由非线性限幅（供电轨、增益压缩）把幅度稳定下来；
  • 仿真中电路可能停在零平衡点不动，因为没有初始扰动——用 .ic 或噪声源踢一脚（实验 16-1）。

振荡频率的粗略估计：N 级环形振荡器 f ≈ 1/(2Nτ·k)，其中 τ 是每级 RC 时间常数、k 为与级数相关的系数；精确值以 .tran 测周期为准。

§16.4四类振荡器对照

类型选频/定时频率稳定度典型用途
RC / 环形R·C 或门延时低，随 PVT 明显变化片上时钟、简单时基
LC / 谐振1/(2π√LC)中，取决于 Q射频振荡、VCO
晶体 / MEMS机械谐振高（ppm 级）系统时钟、通信基准
555 定时器外部 R、C 充放电中低PWM、单稳态、教学

分析时都问同一组问题：能量从哪里补充（有源器件）、相位条件在哪里满足（选频网络）、幅度靠什么限制（非线性）、起振扰动从哪来。回答完这四问，任何振荡电路都能拆开。

§仿真实验

实验 16-1：三级环形振荡器起振

* Ch16 Three-stage ring oscillator with RC delays
B1 y1 0 V=5*tanh(-20*V(z3))
R1 y1 z1 10k
C1 z1 0 10n
B2 y2 0 V=5*tanh(-20*V(z1))
R2 y2 z2 10k
C2 z2 0 10n
B3 y3 0 V=5*tanh(-20*V(z2))
R3 y3 z3 10k
C3 z3 0 10n
.ic V(z1)=0.1
.tran 0 5m 0 1u
.options plotwinsize=0
.end

操作：Run → Add Trace → V(z1)、V(z2)、V(z3)，观察三级相位差与起振过程。　预期与判读：每级 RC 约 100 µs，三级总环路满足振荡条件；约数个时间常数后幅度稳定在 ±5 V 附近，三级波形相差约 120°。删掉 .ic 行可能停在零解不动。　文件位置：part2/16-comparator-oscillator/sim/16-ring-oscillator.cir

§常见误区

  • 用 .ac 分析振荡器：小信号线性化看不到限幅后的稳态幅度。
  • 仿真中电路停在平衡点不起振，其实只缺一个初始扰动。
  • 把比较器当运放用，忽略了输出饱和与恢复时间。

§习题与思考

  1. 把 C1～C3 加倍，测量周期变化并解释。
  2. 把反相级改成 5 级，预测频率与相位关系。

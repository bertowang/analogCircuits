§12.1核心概念速览

  • 一阶低通 H(s) = A0/(1+s/ωp)：低于 ωp 增益平坦，高于后 −20 dB/dec、相位滞后最多 90°。
  • 密勒效应：跨接在增益为 −A 的反相级输入输出之间的电容 C，等效到输入端变成 C(1+A)，到输出端约 C。一个小小的 Cgd 因此可以主导整个带宽。
  • 主极点近似：若第一个极点远低于其余极点，可只保留它；此时 GBW ≈ A0·fp1，闭环增益越低、带宽越宽。
  • 右半平面零点（如共源级的 Cgd 前馈通路）：幅度上升而相位继续滞后，恶化相位裕度，密勒补偿必须配合调零电阻。
  • 节点电阻越大、电容越大，该节点极点越低；找主极点＝找“高阻 × 大电容”的那个节点。

§仿真实验

实验 12-1：Cgd 变化如何移动主极点

* Ch12 Miller effect: Cgd moves the dominant pole
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
.param CGD=1p
VDD vdd 0 DC 5
VIN in 0 DC 1.5 AC 0.01 SINE(1.5 0.01 1k)
RD vdd out 2k
M1 out in 0 0 NM1 W=10u L=1u
CGD1 out in {CGD}
CL out 0 5p
.step param CGD list 0.1p 1p 5p
.ac dec 30 1k 100Meg
.end

操作：Run → Add Trace → V(out)，比较 3 条曲线的 -3 dB 频率。　预期与判读：增益约 −3.85（≈ 11.7 dB），Cgd 经密勒等效放大约 (1+3.85) 倍后并入输入电容；CGD 从 0.1p 增到 5p，带宽明显下降。　文件位置：part2/12-frequency-response/sim/12-miller-effect.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 只按电容绝对值判断主极点，忽略它所在节点的阻抗与增益。
  • 把 .ac 的相位显示误读为“延时”。
  • 在瞬态仿真里用方波测带宽，却没考虑压摆率限制。

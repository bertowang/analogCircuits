§12.1核心概念速览

  • 一阶低通 H(s) = A0/(1+s/ωp)：低于 ωp 增益平坦，高于后 −20 dB/dec、相位滞后最多 90°。
  • 密勒效应：跨接在增益为 −A 的反相级输入输出之间的电容 C，等效到输入端变成 C(1+A)，到输出端约 C。一个小小的 Cgd 因此可以主导整个带宽。
  • 主极点近似：若第一个极点远低于其余极点，可只保留它；此时 GBW ≈ A0·fp1，闭环增益越低、带宽越宽。
  • 右半平面零点（如共源级的 Cgd 前馈通路）：幅度上升而相位继续滞后，恶化相位裕度，密勒补偿必须配合调零电阻。
  • 节点电阻越大、电容越大，该节点极点越低；找主极点＝找“高阻 × 大电容”的那个节点。

§12.2单极点系统的波特图

把 H(s) = A0/(1+s/ωp) 中的 s = jω 代入：

|H| = A0/√(1+(ω/ωp)²)，　φ = −arctan(ω/ωp)
频率幅度相位
ω ≪ ωp≈ A0（0 dB 平坦）≈ 0°
ω = ωpA0/√2（−3 dB）−45°
ω ≫ ωp−20 dB/dec 下降→ −90°

高频段 |H| ≈ A0ωp/ω，所以 GBW = A0·fp 是常数：闭环增益降一半，带宽就翻倍。这条守恒关系是第 13 章稳定性分析与第 20 章运放选型的核心依据。

§12.3密勒等效的推导

设电容 C 跨接在增益为 Av = −A（A > 0）的反相级输入 x 与输出 y 之间。流过它的电流：

i = sC(vx − vy) = sC(1+A)vx　⇒　Zin = 1/[sC(1+A)]

即输入端看到一个被放大 (1+A) 倍的电容；输出端等效约 C/(1+1/A) ≈ C。一个 0.1 pF 的 Cgd 在增益 −4 的共源级里会变成 0.5 pF，若前级是 100 kΩ 高阻节点，主极点立刻降到几百 kHz。

因此判断主极点的实用口诀是：找「高节点阻抗 × 大等效电容 × 附近有大增益」的那个节点，而不是单纯找电容量最大的电容。实验 12-1 用 .step param CGD 把这条结论直接画出来。

§12.4主极点近似、零点与极点分裂

多级电路有多个极点，但若最低极点远低于其余（一般差 3 倍以上），可只保留它：

H(s) ≈ A0 / [ (1+s/ωp1)(1+s/ωp2)… ] ≈ A0/(1+s/ωp1)

两条必须记住的例外：

  • 右半平面零点（s = +ωz）：幅度按 +20 dB/dec 上升，相位却像极点一样继续滞后，对稳定性伤害最大。共源级 Cgd 的前馈通路就产生 ωz = gm/Cgd；密勒补偿常串联调零电阻把它推到左半平面或推到高频。
  • 极点分裂：加补偿电容后主极点变低、次极点变高，二者被「推开」，这正是第 13 章改善相位裕度的物理机制。

§仿真实验

实验 12-1：Cgd 变化如何移动主极点

* Ch12 Miller effect: Cgd moves the dominant pole
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
.param CGD=1p
VDD vdd 0 DC 5
VIN in 0 DC 1.5 AC 0.01 SINE(1.5 0.01 1k)
RD vdd out 2k
M1 out in 0 0 NM1 W=10u L=1u
CGD1 out in {CGD}
CL out 0 5p
.step param CGD list 0.1p 1p 5p
.ac dec 30 1k 100Meg
.end

操作：Run → Add Trace → V(out)，比较 3 条曲线的 -3 dB 频率。　预期与判读：增益约 −3.85（≈ 11.7 dB），Cgd 经密勒等效放大约 (1+3.85) 倍后并入输入电容；CGD 从 0.1p 增到 5p，带宽明显下降。　文件位置：part2/12-frequency-response/sim/12-miller-effect.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 只按电容绝对值判断主极点，忽略它所在节点的阻抗与增益。
  • 把 .ac 的相位显示误读为“延时”。
  • 在瞬态仿真里用方波测带宽，却没考虑压摆率限制。

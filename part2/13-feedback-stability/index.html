§13.1核心概念速览

  • 四种拓扑按“采样输出的是电压还是电流、输入端是串联还是并联混合”分类：电压串联（同相放大）、电压并联（反相放大）、电流串联、电流并联。
  • 闭环 Acl = A/(1+Aβ)；当 Aβ ≫ 1 时 Acl ≈ 1/β，与开环增益无关——这就是“用增益换稳定”。
  • 稳定性判据：在环路增益 |Aβ| = 1 的频率处，相位滞后必须小于 180°；差值就是相位裕度，工程上一般留 45°～60°。
  • 两级放大器有两个低频极点，容易裕度不足；密勒补偿把主极点推低、次极点推高（极点分裂），用带宽换稳定。
  • 时域征兆：阶跃响应过冲大、长时间振铃 ≈ 相位裕度不足；持续等幅振荡 ≈ 已失稳。

§13.2四种反馈拓扑与闭环增益

拓扑输出采样输入混合典型电路对阻抗的影响
电压串联电压串联同相放大器Rin↑、Rout↓
电压并联电压并联反相放大器Rin↓、Rout↓
电流串联电流串联跨导级Rin↑、Rout↑
电流并联电流并联电流放大器Rin↓、Rout↑
Acl = A/(1+Aβ)，　Aβ ≫ 1 时　Acl ≈ 1/β

「串联混合提高输入阻抗、并联混合降低输入阻抗；电压采样降低输出阻抗、电流采样提高输出阻抗」——记住这四句，就能从反馈类型反推电路适合驱动什么、被什么驱动。这也是第 9 章三种组态阻抗差异的统一解释。

§13.3环路增益、相位裕度与判据

稳定性看的不是开环增益 A，而是环路增益 T = Aβ。在 |T| = 1（0 dB 交越频率）处：

PM = 180° + ∠T(ωc)　（工程上取 45°～60°）
  • 两个及更多低频极点各贡献最多 −90°，两级放大器合计可接近 −180°，很容易裕度不足；
  • PM 越小，闭环阶跃响应过冲越大、振铃越久；PM ≤ 0 时负反馈在该频率变成正反馈，电路自激；
  • 严格判据是 Nyquist 判据：对含右半平面极点或复杂环路的系统，光看 PM 不够。

仿真里怎么测环路增益？在反馈环上断开一点，注入小信号 AC 源，测返回信号的比值和相位（返回比分析），或用 .step 扫补偿电容观察阶跃响应趋势——实验 13-1 采用后者，更直观且不易接错。

§13.4补偿技术与阶跃响应诊断

补偿的本质是重新安排极点的位置，用带宽换稳定：

方法做法代价
主极点补偿在最低极点节点加电容，把它推得更低带宽大幅下降
密勒补偿电容跨接两级之间，利用极点分裂需处理右半平面零点
调零电阻与补偿电容串联，移动零点位置多一个元件与版图面积
前馈 / 增益分配调整各级增益与电流，改变次极点功耗与噪声预算变化

从 .tran 阶跃波形反推稳定性：无过冲且单调 ≈ 裕度充足；一次过冲后迅速收敛 ≈ 60° 左右；多次等幅衰减振铃 ≈ 30° 以下；持续振荡 ≈ 已失稳。看到振铃先怀疑相位裕度，再怀疑电源去耦与寄生（后者见第 23 章）。

§仿真实验

实验 13-1：补偿电容与阶跃振铃

* Ch13 Feedback loop: ringing vs dominant-pole compensation
.param CC=100p
VIN in 0 DC 0 PULSE(0 0.1 0 1u 1u 1m 2m)
BERR err 0 V=V(in)-V(out)/10
E1 a 0 err 0 10
R1 a b 10k
C1 b 0 1n
E2 c 0 b 0 10
R2 c out 10k
C2 out 0 {CC}
.step param CC list 10p 100p 1n
.tran 0 2m 0 200n
.end

操作：Run → Add Trace → V(out)，比较三条阶跃响应的过冲与振铃。　预期与判读：CC 增大把第二级极点推低，两个极点靠得更近，相位裕度下降，过冲与振铃加剧；把 BERR 中的反馈系数从 1/10 改成 1/100，环路增益变大，也会更接近失稳。　文件位置：part2/13-feedback-stability/sim/13-loop-stability.cir

§常见误区

  • 只看直流闭环增益正确就认为电路稳定。
  • 把“负反馈”当成永远负：高频相移会让它变号。
  • 补偿电容越大越好：它同时牺牲带宽与压摆率。

§习题与思考

  1. 把 CC 设为 1n 并把反馈系数改成 1/100，观察是否出现持续振荡。
  2. 在 C2 上串一个小电阻引入零点，观察振铃是否改善。

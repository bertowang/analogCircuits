§15.1核心概念速览

  • 二阶低通标准式 H(s) = H0ω0²/(s² + (ω0/Q)s + ω0²)；Q 决定谐振峰与过渡带陡峭程度。
  • Butterworth（Q = 0.707）通带最平坦；Bessel 相位线性、阶跃过冲小；Chebyshev 过渡带最陡但通带有纹波。
  • Sallen-Key：正反馈型、元件少、对运放带宽敏感；多反馈（MFB）：反相型、高频特性更好。
  • fc 附近运放开环增益必须远大于噪声增益，否则实际 Q 与 fc 都会偏移——这是“仿真用理想运放、实测不对”的常见原因。

§15.2二阶传递函数与逼近函数

H(s) = H0 ω0² / ( s² + (ω0/Q)s + ω0² )

同一个分母，Q 取不同值给出不同「性格」：

逼近Q（二阶节）通带阶跃 / 相位适合
Bessel≈ 0.58滚降最缓近似线性相位，几乎无过冲脉冲、音频瞬态
Butterworth≈ 0.707最平坦轻微过冲通用测量、抗混叠
Chebyshev大于 0.707有纹波过冲较大需要陡峭过渡带

高阶滤波器由若干二阶节（biquad）级联实现，每节有自己的 ω0 与 Q；阶数越高过渡带越陡，但对元件公差与运放带宽越敏感。

§15.3Sallen-Key 设计步骤

实验 15-1 用单位增益（电压跟随器型）Sallen-Key，取 R1 = R2 = R：

fc = 1/(2πRC)，　Q = √(C1C2) / [ C2 + C1(1−K) ]（K 为运放闭环增益）

设计顺序：

  1. 由目标 fc 先选一个方便的标准电容 C（如 100 nF 用于低频、100 pF 用于高频）。
  2. 算 R = 1/(2πfcC)，检查 R 不要太小（加重运放负载）也不要太大（噪声与寄生敏感）。
  3. 由目标 Q 选 K 或调整 C1/C2 比值；单位增益 K = 1 时，等 R 等 C 得到 Q = 1/3（无峰、过阻尼），想要 Butterworth 需 K = 1.586。
  4. 确认运放 GBW 至少是 K·fc 的 20～50 倍，否则实际 Q 与 fc 都会偏移。
  5. 用 .ac 验证 −3 dB 点、高频斜率（二阶为 −40 dB/dec）与峰值。

§15.4运放非理想带来的偏差

  • 有限带宽：fc 附近开环增益不足，跟随器不再「理想」，Q 被抬高或压低，甚至出现意外峰值。
  • 输出阻抗与压摆率：大信号时滤波器不再是线性系统，阶跃响应被 SR 限制。
  • 输入偏置电流与失调：高阻 RC 网络上的直流误差，经增益放大后可能吃掉后级动态范围。
  • 元件公差：Q 对电阻电容比值很敏感，1% 电阻 + 5% 电容足以让精密滤波器的通带纹波明显变化（第 22 章）。

仿真时把理想 VCVS 换成带主极点的自建模型（第 8 章）再跑一遍 .ac，是检验设计是否「只在理想世界里成立」的最快方法。

§仿真实验

实验 15-1：Sallen-Key 二阶低通

* Ch15 Sallen-Key 2nd-order low-pass (unity-gain follower)
VIN in 0 DC 0 AC 1
R1 in n1 1.6k
R2 n1 n2 1.6k
C2 n2 0 100n
C1 n1 out 100n
E1 oa 0 n2 out 1e5
Ro oa out 100
.ac dec 30 10 100k
.meas AC g10 FIND mag(V(out)) AT 10
.meas AC g1k FIND mag(V(out)) AT 1k
.meas AC g10k FIND mag(V(out)) AT 10k
.end

操作：Run → Add Trace → V(out)，切 dB 看 −40 dB/dec 的高频斜率。　预期与判读：fc = 1/(2π·1.6k·100n) ≈ 995 Hz；单位增益 Sallen-Key 在 R、C 相等时 Q = 0.5（无峰），10 kHz 处约 −40 dB。　文件位置：part2/15-active-filters/sim/15-sallen-key.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 把一阶 RC 的 −20 dB/dec 套到二阶电路上。
  • 忽略运放带宽，实际 fc 与仿真不符。
  • 电容取太小，运放输入电容与 PCB 寄生成为误差主项。

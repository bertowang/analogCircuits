§11.1核心概念速览

  • 任意两路输入可写成 vid = v1 − v2（要放大的）与 vic = (v1+v2)/2（要抑制的）。
  • 半电路法：差模激励下对称面是交流地，电路对折成半个单管共源级；共模激励下对称面开路，尾电流源的有限阻抗决定了共模增益。
  • CMRR = |Ad/Ac|，主要由尾电流源输出阻抗与器件失配决定；提高尾电流源 ro 是首要手段。
  • 用电流镜作有源负载可把双端输出合并成单端，同时把差模增益翻倍——这正是第 19 章案例的结构。
  • 输入共模范围：下限由尾电流管饱和决定，上限由输入管/负载管饱和决定，是数据手册必查参数。

§仿真实验

实验 11-1：差分传输曲线与线性范围

* Ch11 NMOS differential pair transfer curve
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
VDD vdd 0 DC 5
ISS tail 0 200u
M1 o1 inp tail 0 NM1 W=10u L=1u
M2 o2 inn tail 0 NM1 W=10u L=1u
R1 vdd o1 10k
R2 vdd o2 10k
VINN inn 0 DC 2
VINP inp 0 DC 2
.dc VINP 1.5 2.5 0.01
.end

操作：Run → Add Trace → 表达式 V(o1)-V(o2)；观察 S 形传输曲线。　预期与判读：VINP = 2 V 时两支路各 100 µA，差分输出为 0；输入差增大到约 ±√2·Vov 时电流几乎全部流向一侧，曲线饱和——这段饱和区正是比较器与限幅放大器的工作依据。　文件位置：part2/11-diff-amp/sim/11-diff-pair.cir

§常见误区

  • 把共模增益当成 0：尾电流源阻抗有限，共模增益不为零。
  • 忽略器件失配：实际 CMRR 常被失配而非理论增益限制。
  • 输入共模电压超出范围，仿真却“还能放大”（模型未体现全部边界）。

§14.1核心概念速览

  • 经典两级结构：差分输入级（提供高增益与 CMRR）+ 共源第二级（提供摆幅）+ 密勒补偿（保证稳定）。
  • 规格分解顺序：增益 → 每级 gm·ro；带宽/相位裕度 → 补偿电容 Cc；摆率 SR = Itail/Cc → 反推尾电流；功耗 → 检查电流预算；噪声/失调 → 反推输入管尺寸。
  • Cc ≈ gm1/(2π·GBW) 量级；次极点应高于约 2～3 倍 GBW 才有足够相位裕度。
  • 输入管取大 W·L、小过驱动有利于降低失调与 1/f 噪声；负载管取大 L 提高 ro。这就是模拟版图里面积与性能的交换。
  • 设计检查表：所有管子饱和？共模范围？摆幅？SR？相位裕度？PSRR/CMRR？功耗？PVT 角？

§14.2两级 CMOS 运放的结构

经典两级运放由三部分组成，职责非常明确：

模块电路提供什么主要代价
第一级NMOS 差分对 + PMOS 电流镜负载高增益、高 CMRR、双端转单端输入共模范围受限
第二级共源放大管 + 电流源负载大输出摆幅、驱动能力引入第二个低频极点
补偿跨接两级的密勒电容 Cc（常串 Rz）极点分裂、保证相位裕度带宽与压摆率下降

信号链：差分输入 → 第一级高阻节点 n1 → 第二级 → 输出。n1 是主极点所在节点，输出是次极点所在节点；Cc 跨接这两点，把主极点推向更低频、次极点推向更高频（第 12 章）。

§14.3从指标到尺寸：一次手算

规格示例：A0 ≥ 60 dB、GBW = 10 MHz、相位裕度 ≥ 60°、负载 5 pF、电源 3.3 V、功耗 ≤ 1 mW、SR ≥ 10 V/µs。

  1. 补偿电容：次极点 ωp2 ≈ gm2/CL 需高于约 2.2 倍 GBW，而 Cc ≈ gm1/(2π·GBW)；先估 gm1 得 Cc 约 1～3 pF。
  2. 尾电流：由 SR = Itail/Cc 反推 Itail = SR·Cc，约 20～30 µA，再定差分对每支路电流与 gm1。
  3. 增益：A0 ≈ (gm1ro1)(gm2ro2)；不足则增大管长 L 提高 ro，或改用 cascode。
  4. 功耗校核：各支路电流之和乘 3.3 V 与 1 mW 比较，超了就回头调电流或放宽 SR。
  5. 噪声与失调：输入管取大 W·L、小 Vov 有利于 1/f 噪声与匹配，但寄生电容变大会拉低次极点——又一处取舍。

几乎每一步都与另一步冲突，所以模拟设计不是解方程，而是反复迭代指标分配。把每次迭代的理由写进第 20 章的设计文档，比最后那组尺寸值更有价值。

§14.5设计检查表

  1. 各工艺角与温度下所有管子是否都饱和？用 .op 逐个查 Vds ≥ Vov。
  2. 输入共模范围与输出摆幅是否覆盖规格？
  3. 直流增益、GBW、相位裕度是否同时达标？.ac 加返回比分析。
  4. 阶跃过冲、建立时间、SR 是否达标？.tran 加 .meas。
  5. CMRR / PSRR / 噪声 / 失调是否满足误差预算（第 18 章）？
  6. 静态功耗与面积是否在预算内？
  7. 蒙特卡洛与最坏情况（第 22 章）是否仍满足规格？
  8. 启动、关断、上电顺序与保护是否考虑？

把这张表作为设计文档最后一页，每轮迭代重跑一次，是工业界与课程设计共通的做法。

§仿真实验

实验 14-1：两级运放行为模型与密勒补偿

* Ch14 Two-stage opamp (behavioural) as unity-gain buffer
.param CM=2p
VIN inp 0 DC 0 AC 1 PULSE(0 0.1 0 1u 1u 100u 200u)
BERR err 0 V=V(inp)-V(out)
E1 a 0 err 0 1e3
R1 a n1 100k
C1 n1 0 1p
E2 b 0 n1 0 100
R2 b out 10k
C2 out 0 1p
CM1 n1 out {CM}
.step param CM list 0.2p 2p 20p
.tran 0 200u 0 20n
.ac dec 20 1k 100Meg
.end

操作：Run → 瞬态看单位增益阶跃响应（3 条曲线），.ac 看开环形状的差别。　预期与判读：CM 越大，主极点越低、极点分裂越明显，阶跃响应越平稳但越慢；这正是“带宽换相位裕度”的直观演示。　文件位置：part2/14-opamp-design/sim/14-two-stage.cir

§常见误区

  • 只优化增益与带宽，忘了摆率与静态功耗是同一个电流预算。
  • 用理想模型得出“完美”结果，没有做 PVT 与失配检查。
  • 补偿电容取值只看公式，不看次极点位置。

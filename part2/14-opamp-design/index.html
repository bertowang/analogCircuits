§14.1核心概念速览

  • 经典两级结构：差分输入级（提供高增益与 CMRR）+ 共源第二级（提供摆幅）+ 密勒补偿（保证稳定）。
  • 规格分解顺序：增益 → 每级 gm·ro；带宽/相位裕度 → 补偿电容 Cc；摆率 SR = Itail/Cc → 反推尾电流；功耗 → 检查电流预算；噪声/失调 → 反推输入管尺寸。
  • Cc ≈ gm1/(2π·GBW) 量级；次极点应高于约 2～3 倍 GBW 才有足够相位裕度。
  • 输入管取大 W·L、小过驱动有利于降低失调与 1/f 噪声；负载管取大 L 提高 ro。这就是模拟版图里面积与性能的交换。
  • 设计检查表：所有管子饱和？共模范围？摆幅？SR？相位裕度？PSRR/CMRR？功耗？PVT 角？

§仿真实验

实验 14-1：两级运放行为模型与密勒补偿

* Ch14 Two-stage opamp (behavioural) as unity-gain buffer
.param CM=2p
VIN inp 0 DC 0 AC 1 PULSE(0 0.1 0 1u 1u 100u 200u)
BERR err 0 V=V(inp)-V(out)
E1 a 0 err 0 1e3
R1 a n1 100k
C1 n1 0 1p
E2 b 0 n1 0 100
R2 b out 10k
C2 out 0 1p
CM1 n1 out {CM}
.step param CM list 0.2p 2p 20p
.tran 0 200u 0 20n
.ac dec 20 1k 100Meg
.end

操作：Run → 瞬态看单位增益阶跃响应（3 条曲线），.ac 看开环形状的差别。　预期与判读：CM 越大，主极点越低、极点分裂越明显，阶跃响应越平稳但越慢；这正是“带宽换相位裕度”的直观演示。　文件位置：part2/14-opamp-design/sim/14-two-stage.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 只优化增益与带宽，忘了摆率与静态功耗是同一个电流预算。
  • 用理想模型得出“完美”结果，没有做 PVT 与失配检查。
  • 补偿电容取值只看公式，不看次极点位置。

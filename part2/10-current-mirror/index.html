§10.1核心概念速览

  • 电流镜成立的条件：两管 VGS 相同、工艺相同 → ID 按 W/L 成比例复制；误差主要来自沟道长度调制（λ）与阈值失配。
  • 合规电压（compliance）：输出管必须保持饱和，Vout ≥ Vov；低于这个值，镜像电流开始塌陷。
  • cascode：叠一层管子屏蔽输出电压变化，输出阻抗从 ro 提升到约 gmro²，代价是损失摆幅。
  • 带隙基准：把随温度上升的 PTAT（ΔVBE）与随温度下降的 CTAT（VBE）按系数相加，得到约 1.2 V 的零温度系数电压。
  • 启动电路：基准存在“零电流”这个合法但无用的平衡点，必须加一条只在启动时导通的支路把它推离。

§10.2基本电流镜的定量分析

实验 10-1 的电路里，M1 栅漏短接，因此 VGS 由基准电流唯一决定：

VGS = Vto + √( 2IREF / (Kp(W/L)1) )，　IOUT = IREF · (W/L)2/(W/L)1

三条误差来源按重要性排序：

  1. 沟道长度调制：两管 VDS 不同，I ∝ (1+λVDS) 使镜像电流随输出电压漂移；L 取大、λ 取小可缓解。
  2. 阈值与尺寸失配：工艺偏差使两管不再完全相同，是精密电路的主要误差。
  3. 合规电压：输出管必须保持饱和，Vout ≥ Vov，低于此值电流塌陷。

用 .dc VOUT 0 5 扫出来的曲线斜率，正是第一条误差的直接测量；把 Lambda 改成 0 再跑一次，曲线会变平。

§10.3cascode 与宽摆幅镜像

在输出管上再叠一只共栅管，把它栅极接固定偏置，输出管漏极电压被「钉住」，几乎不随 Vout 变化：

Rout, cascode ≈ gm ro²　（比单管 ro 高约 gmro 倍）

镜像精度与增益因此大幅提高，代价是损失摆幅：输出最低电压从 Vov 抬高到约 2Vov + Vbias 余量。低电源电压设计里常用「宽摆幅 / 低压 cascode」把偏置电压精确设为 Vov + Vto，在保住输出阻抗的同时把摆幅损失压回一个 Vov。

这类「多叠一层管子换性能、再想办法把电压余量找回来」的套路，是第 14 章运放设计的主线。

§10.4带隙基准与启动电路

目标是一个与温度、电源、工艺都弱相关的电压。把两种相反温度系数的量加权求和：

  • CTAT：双极管的 VBE 随温度约 −2 mV/℃；
  • PTAT：两个不同电流密度 BJT 的 ΔVBE = VTln(n) 随温度正比上升。
VREF = VBE + K·ΔVBE ≈ 1.2 V（零温度系数，一阶抵消）

为什么一定要启动电路？因为「所有支路电流为零」也是这个电路的合法直流解：没有电流就没有 ΔVBE，误差放大器毫无理由把电路推离零点。启动支路在上电瞬间注入一股小电流，待基准建立后自动关断，避免影响正常工作。

读基准电路时，先找 PTAT 支路（不同面积的 BJT + 电阻），再找把 PTAT 与 CTAT 相加的运放，最后找那条「看起来多余」的启动管——这三块认清，图就读懂了（第 19 章）。

§仿真实验

实验 10-1：基本电流镜与合规电压

* Ch10 Basic NMOS current mirror: output compliance
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
VDD vdd 0 DC 5
IREF vdd ref 100u
M1 ref ref 0 0 NM1 W=10u L=1u
M2 out ref 0 0 NM1 W=10u L=1u
VOUT out 0 DC 2
.op
.dc VOUT 0 5 0.05
.end

操作：Run → Add Trace → I(VOUT)（或 -I(VOUT)），横坐标是 V(out)。　预期与判读：Vref ≈ Vto + Vov ≈ 0.5 + 0.316 = 0.816 V；当 V(out) 大于约 0.32 V 后 M2 进入饱和，电流接近 100 µA；曲线缓慢上翘的斜率正是 λ 造成的误差。　文件位置：part2/10-current-mirror/sim/10-current-mirror.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 以为电流镜在任何输出电压下都成立：合规电压是硬约束。
  • 忽略 M1 二极管连接支路的压降预算。
  • 设计基准时忘记启动电路，仿真可能停在零电流解。

§习题与思考

  1. 把 M2 的 W 改成 20u，验证输出电流是否翻倍。
  2. 把 Lambda 改成 0，比较输出曲线的平坦度。

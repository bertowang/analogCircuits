§18.1核心概念速览

  • 电阻热噪声 vn = √(4kTR·B)；MOS/BJT 有沟道/散粒噪声；低频还有 1/f 噪声（与工艺、面积强相关）。
  • 把各级噪声折算到输入端（等效输入噪声）才能统一比较；前级增益越高，后级噪声越不重要。
  • .noise 给噪声密度与积分总噪声；.four 给指定基波的谐波分量与 THD。做频谱分析要关掉波形压缩（.options plotwinsize=0）。
  • 误差预算表：把失调、噪声、增益误差、温漂、电源抑制、非线性逐项列出，标注“相关/独立”与 RMS 合成方式，找出最大的一两项去优化——这比盲目换运放有效得多。

§仿真实验

实验 18-1：噪声分析

* Ch18 Noise analysis of an RC + gain stage
VIN in 0 DC 0 AC 1
R1 in n1 1k
C1 n1 0 100n
E1 out 0 n1 0 10
.noise V(out) VIN dec 20 10 1Meg
.end

操作：Run → Add Trace → V(onoise)（输出噪声密度）与 V(inoise)（等效输入噪声）。　预期与判读：1 kΩ 电阻在室温下约 4 nV/√Hz；经 10 倍增益后输出噪声密度约 40 nV/√Hz，并在 RC 截止频率后随信号一起滚降。　文件位置：part2/18-noise-distortion/sim/18-noise.cir

实验 18-2：削顶失真的频谱与 THD

* Ch18 THD of a hard-clipped sine via .four
VIN in 0 SINE(0 1 1k)
B1 out 0 V=max(-0.8,min(0.8,V(in)))
.tran 0 20m 0 2u
.four 1k V(out)
.options plotwinsize=0
.end

操作：Run → Add Trace → V(out) 看削顶波形；View → SPICE Error Log 读 Fourier 分析结果与 THD。　预期与判读：对称削顶只产生奇次谐波（3f、5f…）；THD 随削顶深度上升。也可在波形窗口右键 → View → FFT 交互查看。　文件位置：part2/18-noise-distortion/sim/18-thd.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 用理想源做噪声分析，得到 0 噪声却以为电路无噪声。
  • 波形压缩开启时做 FFT，频谱出现不应有的杂散。
  • 把各项误差直接相加：独立随机误差应按均方根合成。

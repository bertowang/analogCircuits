§18.1核心概念速览

  • 电阻热噪声 vn = √(4kTR·B)；MOS/BJT 有沟道/散粒噪声；低频还有 1/f 噪声（与工艺、面积强相关）。
  • 把各级噪声折算到输入端（等效输入噪声）才能统一比较；前级增益越高，后级噪声越不重要。
  • .noise 给噪声密度与积分总噪声；.four 给指定基波的谐波分量与 THD。做频谱分析要关掉波形压缩（.options plotwinsize=0）。
  • 误差预算表：把失调、噪声、增益误差、温漂、电源抑制、非线性逐项列出，标注“相关/独立”与 RMS 合成方式，找出最大的一两项去优化——这比盲目换运放有效得多。

§18.2噪声源与等效输入噪声

类型表达式特征对策
电阻热噪声vn = √(4kTR·B)白噪声，1 kΩ ≈ 4 nV/√Hz减小阻值、缩小带宽
散粒噪声in = √(2qI·B)与直流电流成正比降低偏置电流
1/f（闪烁）噪声∝ 1/f低频主导，MOS 明显增大器件面积、斩波、P 管输入

把各级噪声都折算到输入端（除以该级之前的增益），得到等效输入噪声，才能在同一个尺度上比较。由此得到模拟前端最重要的结论：第一级的增益与噪声几乎决定整个系统，后面各级的噪声被前级增益除掉后通常可以忽略。

带宽要注意：白噪声的积分用的是噪声带宽而非 −3 dB 带宽，一阶低通的噪声带宽为 1.57·fc。实验 18-1 的 .noise 输出里 V(onoise) 是密度、积分曲线是总噪声，二者不要混用。

§18.3失真、谐波与 THD

非线性使输出出现输入没有的频率分量。对称削顶（实验 18-2）只产生奇次谐波 3f、5f…，非对称失真还会产生偶次谐波。

THD = √(V2²+V3²+…)/V1

用 .four 1k V(out) 得到各次谐波幅值与 THD，前提是：仿真时间足够长以进入稳态、只取整数个周期、关掉波形压缩（.options plotwinsize=0）。否则频谱会出现本不存在的杂散。

与噪声的区别很关键：噪声与信号幅度无关，决定了能分辨的最小信号；失真随信号幅度急剧增大，决定了最大不失真信号。两者之间的距离就是动态范围，常用 SNR、SINAD、ENOB 描述（数据转换器接口必查）。

§18.4误差预算表

不要凭感觉换运放，先把误差逐项列出来：

误差项典型来源量级示例合成方式
增益误差电阻公差、有限开环增益0.1% + 0.01%系统项，按最坏情况相加
失调与温漂VOS、dVOS/dT100 µV + 2 µV/℃系统项，按最坏情况相加
噪声热噪声、1/f、电源纹波耦合10 µVrms随机项，按均方根合成
非线性摆幅、压摆率、THD0.01%单独设上限
PSRR / CMRR电源与共模泄漏60 dB按实际纹波折算

两类误差不能简单相加：独立的随机项按 √(Σei²) 合成，系统性偏差按最坏情况直接相加。填完表后，找出最大的一两项去优化，收益远高于把所有器件都升级一档。

§仿真实验

实验 18-1：噪声分析

* Ch18 Noise analysis of an RC + gain stage
VIN in 0 DC 0 AC 1
R1 in n1 1k
C1 n1 0 100n
E1 out 0 n1 0 10
.noise V(out) VIN dec 20 10 1Meg
.end

操作：Run → Add Trace → V(onoise)（输出噪声密度）与 V(inoise)（等效输入噪声）。　预期与判读：1 kΩ 电阻在室温下约 4 nV/√Hz；经 10 倍增益后输出噪声密度约 40 nV/√Hz，并在 RC 截止频率后随信号一起滚降。　文件位置：part2/18-noise-distortion/sim/18-noise.cir

实验 18-2：削顶失真的频谱与 THD

* Ch18 THD of a hard-clipped sine via .four
VIN in 0 SINE(0 1 1k)
B1 out 0 V=max(-0.8,min(0.8,V(in)))
.tran 0 20m 0 2u
.four 1k V(out)
.options plotwinsize=0
.end

操作：Run → Add Trace → V(out) 看削顶波形；View → SPICE Error Log 读 Fourier 分析结果与 THD。　预期与判读：对称削顶只产生奇次谐波（3f、5f…）；THD 随削顶深度上升。也可在波形窗口右键 → View → FFT 交互查看。　文件位置：part2/18-noise-distortion/sim/18-thd.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 用理想源做噪声分析，得到 0 噪声却以为电路无噪声。
  • 波形压缩开启时做 FFT，频谱出现不应有的杂散。
  • 把各项误差直接相加：独立随机误差应按均方根合成。

§习题与思考

  1. 把实验 18-1 的 R1 增大 100 倍，验证噪声密度按 √R 增长。

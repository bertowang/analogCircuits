§6.1三个工作区与判据

以增强型 NMOS 为例（源极接地、体接地），令过驱动电压 Vov = VGS − Vto：

工作区判据电流用途
截止VGS < VtoID ≈ 0开关断开
线性 / 三极管区VGS > Vto 且 VDS < VovID ≈ μnCox(W/L)[VovVDS − VDS²/2]开关闭合、可变电阻
饱和区VGS > Vto 且 VDS ≥ VovID ≈ ½ μnCox(W/L) Vov² (1+λVDS)放大器必须在这里

在 SPICE Level-1 模型里 Kp = μCox。下方实验用 Kp=200u、W/L=10，于是 ½·Kp·(W/L) = 1 mA/V²：Vov = 1 V 时 ID ≈ 1 mA，很好记。

§6.2小信号模型：把非线性变成线性

在静态工作点附近做泰勒展开，只保留一阶项，MOS 就变成三个元件：

gm = 2ID/Vov = √(2 Kp(W/L) ID)，　ro ≈ 1/(λ ID)，　A0 = gmro
  • 压控电流源 gmvgs：栅压变化引起漏流变化，这是放大的来源。
  • 输出电阻 ro：沟道长度调制（λ）造成；λ 越小、L 越大，ro 越大。
  • 栅极开路：低频下输入电阻极高，这是 MOS 相对 BJT 的关键优势。

共源放大器增益 Av ≈ −gm(RD ∥ ro)。用实验 6-2 的参数：ID ≈ 1 mA，gm = 2 mA/V，ro = 50k，RD∥ro = 1.92k → 增益 ≈ −3.85，与仿真相符。

§6.3同一张图，两种读法

大信号读法：把电容开路、电感短路、交流源置零，只留直流电源 → 求静态工作点（每个管子在哪个区、V(out) 是多少、摆幅还剩多少）。小信号读法：把直流电源置为交流地、把耦合/旁路电容视为短路、把管子换成 gm/ro 模型 → 求增益、阻抗、带宽。

这两套视图的切换是模拟电路最重要的思维动作，也是第 19 章十步法的第 4、5 步。仿真里对应 .op（大信号）与 .ac（小信号）。

§6.4读输出特性曲线族

实验 6-1 画出 ID–VDS 曲线，每条对应一个 VGS。读图时看三处：

  1. 左侧陡升段 = 线性区；右侧近似水平段 = 饱和区，两段的分界约在 VDS = Vov。
  2. 水平段的斜率 = 1/ro（λ 越大越斜）；水平段的高度随 VGS 按平方律增长。
  3. 把负载电阻的 I–V 关系也画上去（负载线），两线交点就是静态工作点。

§仿真实验

实验 6-1：NMOS 输出特性曲线族

* Ch06 NMOS Id-Vds family by VGS stepping
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
.param VGSET=1.5
VDS d 0 DC 0
VGS g 0 DC {VGSET}
M1 d g 0 0 NM1 W=10u L=1u
.dc VDS 0 3 0.02
.step param VGSET list 1.0 1.5 2.0 2.5
.end

操作：Run → Add Trace → I(M1)（或 Id(M1)），可看到 4 条曲线。　预期与判读：VGS=1.5 V 时 Vov=1 V，饱和区 Id ≈ 1 mA；VGS=2.5 V 时 Vov=2 V，Id ≈ 4 mA（平方律）。曲线右端上翘来自 Lambda。　文件位置：part1/06-mosfet/sim/06-mos-iv.cir

实验 6-2：共源放大的工作点与增益

* Ch06 Common-source amplifier: .op, .ac and .tran
.model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)
VDD vdd 0 DC 5
VIN in 0 DC 1.5 AC 0.01 SINE(1.5 0.01 1k)
RD vdd out 2k
M1 out in 0 0 NM1 W=10u L=1u
.op
.ac dec 20 100 10Meg
.tran 0 5m 0 2u
.meas TRAN vin_pp PP V(in) FROM 2m
.meas TRAN vout_pp PP V(out) FROM 2m
.end

操作：Run → Error Log 读工作点（Id、gm、Vout）与两条 .meas；Add Trace 看 V(out) 与 V(in) 反相。　预期与判读：V(out) ≈ 3 V，Id ≈ 1 mA，gm ≈ 2 mS；增益 ≈ −3.85（输出与输入反相）。把 RD 改成 4k，先检查输出是否仍有足够 VDS 维持饱和，再看增益是否翻倍。　文件位置：part1/06-mosfet/sim/06-common-source.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 把 VDS ≥ Vov 记成 VDS ≥ Vto：饱和判据用的是过驱动电压。
  • 用 .ac 仿真时忘了给源写 AC 幅值，结果全为 0。
  • 只看增益不看工作点：RD 太大会把管子推入线性区，公式失效。
  • 把体（bulk）随便接地：集成电路里 NMOS 体接最低电位，PMOS 体接最高电位；体效应会抬高 Vto。

§习题与思考

  1. 在实验 6-2 中加 500 Ω 源极退化电阻，先手算增益再仿真（提示：增益约 −RD/(RS+1/gm)）。
  2. 把 L 从 1u 改成 2u，解释 Id、gm、ro 各自怎么变。
  3. 用 .op 输出确认 M1 处于饱和区，并写出验证所用的两个电压值。

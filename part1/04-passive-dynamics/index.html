§4.2一阶电路的三要素法

任何只含一个储能元件的线性电路，响应都可以用三个数写出来，不必解微分方程：

v(t) = v(∞) + [ v(0⁺) − v(∞) ] · e−t/τ
  • 初值 v(0⁺)：电容电压（或电感电流）不能突变，等于换路前的 v(0⁻)。
  • 终值 v(∞)：把电容开路、电感短路，按直流电路求解。
  • 时间常数 τ：把独立源置零（电压源短路、电流源开路），从储能元件两端看进去的等效电阻 Rth，一阶 RC 有 τ = RthC，RL 有 τ = L/Rth。

常用结论：t = τ 时完成 63.2%，t = 3τ 约 95%，t = 5τ 约 99.3%；10%→90% 上升时间 ≈ 2.2τ。实验 4-1 与第 21 章的 .meas 都会用到这些数。

§4.3二阶系统、阻尼与谐振

含 L、C 两个储能元件的电路由二阶微分方程描述，标准形式为：

H(s) = H0 ω0² / ( s² + (ω0/Q)s + ω0² )，　ω0 = 1/√(LC)

也可以写成 s² + 2ζω0s + ω0²，其中阻尼比 ζ = 1/(2Q)：

阻尼条件阶跃响应频域
过阻尼ζ > 1（Q < 0.5）缓慢单调上升，无过冲无谐振峰
临界阻尼ζ = 1最快无过冲平坦
欠阻尼ζ < 1（Q > 0.5）过冲与振铃出现谐振峰，峰值 ≈ Q

串联 RLC 中 Q = (1/R)√(L/C)：R 越小 Q 越大、峰越尖、振铃越久。这与第 13 章的相位裕度／阶跃过冲是完全对应的直觉，只是那里的「阻尼」由反馈环路提供。

§4.4阻抗、相量与传递函数

正弦稳态下把微分运算换成乘法，是频域分析的全部技巧：

元件时域s 域阻抗正弦稳态
电阻v = RiRR
电容i = C dv/dt1/(sC)1/(jωC)
电感v = L di/dtsLjωL

于是分压公式直接给出 RC 低通的传递函数 H(s) = 1/(1+sRC)，一个实极点 s = −1/RC。画波特图的规则：每个极点从它的转折频率起贡献 −20 dB/dec 与最多 −90° 相移，每个零点贡献 +20 dB/dec 与最多 +90°；多个极零点的作用在对数坐标上直接相加。

这一节是第 12 章与第 15 章的共同前置。能把「一个电容 + 一个电阻」翻译成「一个极点」，后面的多路反馈电路就只是把这句话重复几次。

§4.5实际元件的寄生参数

仿真与实测的差异，一半来自这里：

  • 电阻：引线电感、并联寄生电容、公差（1%/5%）、温度系数 ppm/℃；高阻值电阻在高频已不再是纯电阻。
  • 电容：等效串联电阻 ESR、等效串联电感 ESL、漏电流、介质吸收；ESR 决定纹波与整流尖峰，ESL 决定自谐振频率，超过后电容变成电感。
  • 电感：绕组直流电阻、匝间电容、磁芯饱和与损耗。
  • PCB：走线约 1 nH/mm、焊盘到地平面几 pF；这些在几十 MHz 以上就会改变频响（见第 23 章）。

做实验时先跑理想模型确认公式，再逐个加寄生参数看曲线怎么变——这比一上来就用复杂模型更能建立因果直觉。

§仿真实验

实验 4-1：RC 低通的频响

* Ch04 RC low-pass: transfer function and -3dB point
V1 in 0 DC 0 AC 1
R1 in out 1k
C1 out 0 100n
.ac dec 30 10 100k
.meas AC g10 FIND mag(V(out)) AT 10
.meas AC g1k FIND mag(V(out)) AT 1k
.meas AC g10k FIND mag(V(out)) AT 10k
.end

操作：Run → Add Trace → V(out)；纵坐标右键切 dB；Error Log 读三条 .meas。　预期与判读：fc = 1/(2πRC) ≈ 1.59 kHz；10 Hz 处增益 ≈ 1；1 kHz 处 ≈ 0.846；10 kHz 处 ≈ 0.157。　文件位置：part1/04-passive-dynamics/sim/04-rc-lowpass.cir

实验 4-2：RLC 串联谐振

* Ch04 RLC series resonance (voltage across C)
V1 in 0 DC 0 AC 1
R1 in n1 10
L1 n1 out 10m
C1 out 0 100n
.ac dec 40 100 100k
.meas AC peak MAX mag(V(out))
.end

操作：Run → Add Trace → V(out)，观察谐振峰；把 R1 改成 100 再看峰高变化。　预期与判读：f0 = 1/(2π√(LC)) ≈ 5.03 kHz；电容上的峰值电压约等于 Q ≈ (1/R)·√(L/C) ≈ 31.6 倍输入。　文件位置：part1/04-passive-dynamics/sim/04-rlc-resonance.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 把 -3 dB 当成“幅度降为 0.3”：其实是 1/√2 ≈ 0.707。
  • 忽略电容的 ESR，导致高频段仿真与实测不符。
  • 在 .ac 分析里用 SINE 源 expecting 时域波形：.ac 只看 AC 幅值。

§习题与思考

  1. 手算实验 4-1 在 1 kHz 处的相位，再用波形窗口的相位显示核对。
  2. 把实验 4-2 的 R1 依次改为 10 / 100 / 1k，记录峰值与带宽，总结 Q 的规律。

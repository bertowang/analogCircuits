§7.2工作区判据与指数关系

BJT 与 MOS 的推理框架完全一样，只是控制量从 VGS 换成 VBE、输入从「开路」变成「有电流」：

工作区判据（NPN）行为
截止VBE 低于约 0.6 V，且 VBC 反偏IC ≈ 0，开关断开
放大区VBE ≈ 0.6～0.8 V，且 VBC 反偏（VCE > VCE,sat）IC = IS eVBE/VT，放大器必须在此
饱和区发射结与集电结都正偏VCE ≈ 0.2 V，开关闭合

与 MOS 一样，判断顺序是「先假设工作区 → 线性化 → 算电压电流 → 验证结偏置」，即第 5 章的假设—验证法。差别在于 BJT 基极要取电流 IB = IC/β，因此前级会被加载。

§7.3小信号模型与三种组态

gm = IC/VT，　rπ = β/gm，　ro ≈ VA/IC

室温下 VT ≈ 26 mV，所以 IC = 1 mA 时 gm ≈ 38 mS —— 同样电流下 BJT 的跨导远大于 MOS（gm = 2ID/Vov），这是它在低噪声、高精度场合仍被使用的原因。

组态电压增益输入阻抗输出阻抗相位
共射 CE高，−gmRC≈ rπ（中）≈ RC反相
共集 CC（射随）≈ 1高，≈ (β+1)RE低，≈ 1/gm同相
共基 CB高低，≈ 1/gm高同相

三者与 MOS 的共源/共漏/共栅一一对应，只需把 rπ 换成「无穷大」、把 VBE 换成 VGS。建议把这张表和第 6 章的表并排抄一次。

§7.4分压偏置：让电路不依赖 β

β 随器件、温度、电流可能变化 2～3 倍，所以「一个电阻定基极电流」的偏置不可用。实验 7-1 用的是分压偏置加发射极电阻：

VB ≈ VCC·R2/(R1+R2)，　IE ≈ (VB − 0.7 V)/RE

成立条件是分压电流远大于基极电流（一般取 Idiv ≥ 10 IB）。RE 引入直流负反馈：温度上升 → IC 上升 → VE 上升 → VBE 下降 → 抑制 IC，从而稳定工作点。交流增益若要恢复，可给 RE 并联旁路电容，或只旁路一部分（局部退化，见第 9 章）。

设计顺序：先定 IC（由功耗与 gm 决定）→ 定 VE（约 10%～20% VCC）→ 算 RE → 由 VB 选分压比 → 校核分压电流 → 由目标 VC 定 RC → 最后检查 VCE 是否留在放大区。

§7.5BJT 与 MOS 对照表

维度BJTMOSFET
控制量VBE（指数律）VGS（平方律）
输入阻抗有限（rπ），需基极电流极高，栅极几乎不取电流
同电流跨导大（IC/VT）较小（2ID/Vov）
低频噪声 / 失调通常更优1/f 噪声较明显
开关应用有饱和压降、需驱动电流导通电阻可控、驱动简单
集成工艺双极 / BiCMOS主流 CMOS

没有谁更好，只有谁更适合：传感器前端、精密基准常见 BJT/双极输入；大规模混合信号与开关电路几乎都用 CMOS。读数据手册时先看输入偏置电流与噪声密度，往往就能猜出输入级用的是哪一种。

§仿真实验

实验 7-1：分压偏置的共射放大器

* Ch07 Common-emitter amplifier with divider bias
.model NPN1 NPN(Is=1e-15 Bf=200 Vaf=100)
VDD vdd 0 DC 12
R1 vdd base 100k
R2 base 0 20k
RC vdd out 4.7k
RE emit 0 1k
Q1 out base emit NPN1
VIN in 0 DC 0 AC 0.01 SINE(0 0.01 1k)
CIN base in 10u
.op
.tran 0 5m 0 2u
.ac dec 20 10 1Meg
.end

操作：Run → Error Log 读静态工作点；Add Trace 看 V(out) 与 V(in) 的相位关系。　预期与判读：基极约 2 V、发射极约 1.3 V、Ie ≈ 1.3 mA、Vc ≈ 5.9 V；增益约 −gm·RC，其中 gm ≈ Ic/26mV ≈ 50 mS，故增益可达上百倍（本例受 RE 影响会小一些）。　文件位置：part1/07-bjt/sim/07-common-emitter.cir

§常见误区

  • 把 β 当成设计常量：β 随器件、温度、电流大幅变化，好的偏置电路必须对它不敏感。
  • 忘记基极电流会加载分压器：分压电流应远大于 Ib。
  • 把共集（射随器）误认为没有增益就“没用”：它的价值是阻抗变换。

§习题与思考

  1. 把 RE 拆成两半，只旁路一半，推导并仿真验证增益变化。
  2. 把 CIN 改成 100n，用 .ac 观察低频截止点如何上移。

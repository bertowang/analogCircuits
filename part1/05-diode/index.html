§5.1指数模型与三个近似层

PN 结的直流行为由肖克利方程描述：

ID = IS ( eVD/(n VT) − 1 )，　VT = kT/q ≈ 26 mV（室温）

手算时按精度需求选一层近似，这一步选择本身就是读图能力：

模型假设适用
理想开关正偏短路、反偏开路判断整流电路“哪条路通”，做逻辑级分析
恒压降导通后 VD ≈ 0.7 V（硅）手算输出电压、限幅电平
分段线性0.7 V + 小电阻 rd估算纹波、导通压降随电流变化
指数 / SPICE完整方程 + 结电容 + 反向恢复仿真、小信号电阻 rd = nVT/ID、温度特性

§5.2假设—验证法：读二极管电路的通用动作

  1. 先假设每个二极管的状态（导通 / 截止），把导通的换成 0.7 V 电压源，截止的换成开路。
  2. 在这个线性化的电路里求各节点电压与二极管电流。
  3. 逐条验证：假设导通的，电流方向是否为正？假设截止的，阳极电位是否真的低于阴极 + 0.7 V？
  4. 若有矛盾，改假设重算。两个以上二极管时，从最“确定”的那个开始（例如接最高电位的那一路）。
迁移价值

同样的动作会反复出现在第 6 章判断 MOS 工作区、第 7 章判断 BJT 放大/饱和、第 16 章判断比较器状态。先假设、再线性化、后验证，是所有非线性电路的统一读法。

§5.3整流、滤波与纹波

半波整流只让正半周通过；加滤波电容后，电容在峰值附近被充电、在其余时间向负载放电，输出变成带纹波的直流。纹波峰峰值近似：

ΔV ≈ Iload / (f · C)　（半波，f 为电网频率）

电流越大、频率越低、电容越小，纹波越大。全波（桥式）整流的等效充电频率是 2f，纹波减半。仿真里用 .tran 能看到真实的充放电尖峰，这是 .ac 做不到的——非线性电路必须用瞬态分析。

§5.4限幅、钳位与稳压

  • 限幅（clip / limiter）：用二极管把电压钉在某个电平上，常用于保护 ADC 输入。串一个电阻限流是必须的。
  • 钳位（clamp）：电容 + 二极管把整个波形的直流电平搬移，波形形状不变、“底座”变了。
  • 稳压二极管：工作在反向击穿区（SPICE 模型里用 Bv / Ibv 指定），需串联限流电阻，并校核功耗。

§仿真实验

实验 5-1：二极管的 I-V 曲线

* Ch05 Diode I-V curve by DC sweep
.model DGEN D(Is=1n N=1.7 Rs=0.5)
V1 a 0 DC 0
D1 a 0 DGEN
.dc V1 -0.2 0.8 0.005
.end

操作：Run → Add Trace → I(D1)；横坐标是 V(a)。　预期与判读：正向约 0.6～0.7 V 开始明显导通，电流随电压指数上升；反向只有极小的漏电流。　文件位置：part1/05-diode/sim/05-diode-iv.cir

实验 5-2：半波整流与电容滤波

* Ch05 Half-wave rectifier with smoothing capacitor
.model DGEN D(Is=1n N=1.7 Rs=0.5)
V1 ac_in 0 SINE(0 5 50)
D1 ac_in dc_out DGEN
C1 dc_out 0 10u
R1 dc_out 0 1k
.tran 0 100m 0 100u
.meas TRAN vmax MAX V(dc_out)
.meas TRAN vmin MIN V(dc_out) FROM 40m
.end

操作：Run → Add Trace → V(ac_in) 与 V(dc_out)；Error Log 读 vmax / vmin 估算纹波。　预期与判读：峰值约 4.3～4.5 V（扣掉二极管压降）；纹波 ΔV ≈ I/(fC) ≈ 4.3 mA/(50·10µ) ≈ 8.6 V 的估值在轻载下偏大，实际由放电时间常数 10 ms 决定——正好说明近似式的适用边界。把 C1 改成 100u，纹波明显变小。　文件位置：part1/05-diode/sim/05-halfwave.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 用 .ac 分析整流器：非线性电路的小信号线性化会给出完全错误的结果。
  • 二极管直接并在理想电压源上：电流无穷大，仿真必不收敛，必须串限流电阻。
  • 忘记二极管的反向恢复与结电容，高频开关电路里仿真会过于“干净”。

§习题与思考

  1. 把实验 5-2 改成桥式全波整流（4 个二极管），比较纹波频率与幅值。
  2. 用两个二极管搭一个 ±1.4 V 对称限幅器，.tran 验证输出电平。
  3. 改变 .model 里的 Is，观察 I-V 曲线如何平移并解释温度趋势。

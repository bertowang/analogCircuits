§3.1读图第一步：标节点、定参考地

电压永远是两点之间的差。所谓“某点电压”，默认指它相对参考地（节点 0）的电位。读图时先做三件笨功夫，能消掉一半的错误：

  1. 把所有由理想导线直连的点圈成同一个节点，给每个节点起名字（in、out、bias…），别用自动生成的 N001。
  2. 找出参考地，以及电源正负端；画一条从电源正端经器件到地的直流通路。
  3. 在图上标出你猜的电位高低（+ / −）和电流方向。猜错没关系，算出负值就说明方向反了。

本书所有网表都用有意义的节点名，正是为了训练这个习惯。第 19 章会把它扩展成完整的十步法。

§3.2KCL / KVL 与节点电压法

KCL：任一节点流入电流之和等于流出之和（本质是电荷守恒）。KVL：沿任一闭合回路电压降之和为零（本质是能量守恒）。实际手算时，节点电压法最不容易出错：以地为参考，对每个未知节点写一条“流出电流总和 = 0"，得到线性方程组。

Vout = V1 · (R2 ∥ RL) / [ R1 + (R2 ∥ RL) ]

上式就是下方电路的手算结果：R₂∥R_L = 5k，所以 V(out) = 10 × 5/(10+5) = 3.333 V，而不是“想当然”的 5 V。

§3.3负载效应与戴维南等效

把分压器从 out 看进去：开路电压 Vth = 5 V（R₁=R₂ 时），等效内阻 Rth = R₁∥R₂ = 5k。接上 R_L = 10k 后，输出变成 5 × 10k/(5k+10k) = 3.333 V。戴维南等效是“读懂前后级相互影响”的核心工具：前一级是源，后一级是负载，两者用 Vth 和 Rth 对话。

工程判据：若希望分压比不被后级明显改变，一般要求 Rth ≤ RL/10（即分压电流约为负载电流的 10 倍）。代价是功耗增大——模拟设计里到处都是这种取舍。

§3.4叠加、受控源与 .tf

线性电路中多个独立源的贡献可以分别计算再相加（叠加）；关掉电压源＝短路，关掉电流源＝开路。含受控源（晶体管小信号模型、运放模型）时叠加仍可用，但受控源不能关掉。

.tf V(out) V1 让 SPICE 直接给出三件事：直流小信号增益 V(out)/V1、从 V1 看进去的输入电阻、从 out 看进去的输出电阻。它是验证戴维南手算最快的工具。

§仿真实验

实验 3-1：分压器、负载效应与 .tf 验证

* Ch03 Divider with load: verify Thevenin by .tf
V1 in 0 DC 10
R1 in out 10k
R2 out 0 10k
RL out 0 10k
.op
.tf V(out) V1
.end

操作：Run → View → SPICE Error Log，读 V(out)、transfer function、input / output impedance。　预期与判读：V(out) = 3.333 V；V(out)/V1 = 0.3333；从 V1 看进去 R_in = R1 + (R2∥RL) = 15k；从 out 看进去 R_out = R1∥R2 = 5k。　文件位置：part1/03-circuit-laws/sim/03-divider-thevenin.cir

实验 3-2：负载从 1k 扫到 1Meg

* Ch03 Load effect sweep
.param RLv=10k
V1 in 0 DC 10
R1 in out 10k
R2 out 0 10k
RL out 0 {RLv}
.step param RLv list 1k 10k 100k 1Meg
.op
.meas OP vout FIND V(out)
.end

操作：Run → Error Log 里比较 4 个 vout；或把 V(out) 加到波形窗口看随 step 的变化。　预期与判读：RL = 1k / 10k / 100k / 1Meg 时 V(out) ≈ 0.909 / 3.333 / 4.762 / 4.975 V，逐渐逼近开路值 5 V。　文件位置：part1/03-circuit-laws/sim/03-load-sweep.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 忘了后级输入阻抗也是负载，把分压器当理想电压源。
  • 把参考地当成“真实的地”：它只是人为选定的零电位参考点。
  • KCL 方程里电流方向随意混用，导致符号错误；先统一假设方向再写。

§习题与思考

  1. 手算 R1=4.7k、R2=10k、RL=2.2k 时的 V(out)，再用实验 3-1 的网表改值核对。
  2. 用 .tf 求实验 3-2 在 RL=100k 时的输出电阻，解释为何与 R1∥R2 有关。

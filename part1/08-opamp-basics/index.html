§8.1三条假设与虚短虚断的适用条件

理想运放：开环增益无穷大、输入电阻无穷大、输出电阻为零。由此得到教科书里的两条捷径：

  • 虚断：输入端不取电流（i₊ = i₋ = 0）——只要运放未损坏，这条基本总成立。
  • 虚短：v₊ = v₋ —— 仅在“负反馈 + 线性区”时才成立。
最常见的误用

比较器工作在开环、输出饱和，此时 v₊ ≠ v₋，虚短完全失效。判断顺序永远是：先找反馈通路 → 判断正负 → 假设线性区求解 → 再检查输出是否落在电源轨内；若超出，则改为饱和模型重算。这与第 5 章的“假设—验证”是同一个动作。

§8.2四种基本组态

组态闭环增益输入电阻典型用途
电压跟随器1极高缓冲、隔离前后级
同相放大1 + R2/R3极高传感器信号放大
反相放大−Rf/Rin≈ Rin求和、跨阻、反相
差分 / 仪表放大R2/R1（匹配时）由输入电阻决定桥式传感器、抑制共模

下方实验中 R2 = 1k、R3 = 9k，同相增益 = 1 + 9/1 = 10。注意闭环增益只由电阻比决定，与开环增益无关——这正是负反馈用“增益换稳定与线性”的核心思想，第 13 章会展开。

§8.3用 E 源自建一个运放

与其调用厂商模型，不如亲手搭一次，把“理想运放”看透。网表里 E1 int 0 in minus 1e5 是一个压控电压源：输出 = 1e5 × (v(in) − v(minus))，就是开环增益 1e5。再串一个 R = 1k、C = 1 µF 的低通，得到约 159 Hz 的主极点，于是增益带宽积 ≈ 1e5 × 159 Hz ≈ 16 MHz。

这个自建模型自带“真实感”：增益有限、带宽有限、会相位滞后，却没有任何黑盒。后续第 13、14、17、20 章的反馈与稳定性实验都用它。

§8.4理想模型的四个边界

  1. 输出摆幅：不能超出电源轨；轨到轨运放也只是接近。
  2. 压摆率 SR：大信号时输出电压变化速率有上限，正弦波会出现三角化失真。
  3. 带宽与相位裕度：闭环增益越高，可用带宽越窄；反馈过深会振荡。
  4. 非理想输入：输入失调电压 Vos、输入偏置电流 Ib、共模抑制比 CMRR、噪声，决定了直流精度下限。

看到数据手册时，按这四类去查参数，就不会被几十页指标淹没。

§仿真实验

实验 8-1：用 VCVS 搭同相放大器

* Ch08 Non-inverting amplifier from a self-built opamp model
* E1 = open-loop gain 1e5 ; R1/C1 = dominant pole near 159 Hz
VIN in 0 DC 0 AC 1 SINE(0 0.5 1k)
E1 int 0 in minus 1e5
R1 int oa 1k
C1 oa 0 1u
R2 oa minus 1k
R3 minus 0 9k
.op
.tran 0 5m 0 5u
.ac dec 20 1 10Meg
.meas AC gain1k FIND mag(V(oa)) AT 1k
.end

操作：Run → Add Trace → V(oa) 与 V(in)；.ac 结果里看闭环增益约 20 dB 的平坦段与高频滚降。　预期与判读：闭环增益 1 + 9k/1k = 10（20 dB）；V(in)=0.5 V 峰值时 V(oa)=5 V（模型无电源轨限制）；带宽约 GBW/10 ≈ 1.6 MHz。　文件位置：part1/08-opamp-basics/sim/08-noninverting.cir

实验 8-2：开环增益与虚短的边界

* Ch08 Open-loop opamp: virtual short does NOT hold
VIN in 0 DC 0 AC 1
E1 int 0 in 0 1e5
R1 int oa 1k
C1 oa 0 1u
.op
.ac dec 20 1 10Meg
.meas AC aol_1k FIND mag(V(oa)) AT 1k
.end

操作：Run → Add Trace → V(oa)；与实验 8-1 的闭环曲线对比。　预期与判读：低频开环增益 1e5（100 dB），约 159 Hz 后以 −20 dB/dec 下降；开环时输出极易饱和，虚短不成立。　文件位置：part1/08-opamp-basics/sim/08-openloop.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 对比较器使用虚短：开环、饱和状态下不成立。
  • 忘记检查输出是否超出电源轨，算出“正确”却不可能实现的电压。
  • 反馈电阻取到 MΩ 级却忽略输入偏置电流与噪声。
  • 把 .ac 的 1 V 激励当成实际信号幅度：小信号分析只关心比值。

§习题与思考

  1. 把 R3 改成 99k，预测闭环增益与带宽，再用 .ac 验证 GBW 近似守恒。
  2. 在实验 8-1 中把 VIN 幅度提到 5 V，观察自建模型为何仍不失真，并说明真实运放会怎样。
  3. 把 C1 增大 10 倍，解释相位裕度与阶跃响应振铃的趋势。

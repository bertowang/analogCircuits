本书的主张

读懂电路和设计电路是两种可以训练的能力，而不是"看多了自然会"。本书把这两件事拆成明确的步骤（第 19、20 章），再用可运行的仿真把每一步的结论验证一遍。

学习闭环固定为四步：手算 → 仿真 → 改参数看趋势 → 写出结论。只跑仿真不改参数，等于只抄了答案。

运行 LTspice 网表（30 秒）

  1. 安装 ADI LTspice（免费，Windows / macOS 均可）。
  2. 在任意章节的仿真实验里点代码块右上角「复制」，粘贴为纯文本，保存成文件名如 sim/03-divider.cir；或直接使用仓库里同名的 .cir 文件——它们由 tools/extract_netlists.py 从 HTML 代码块自动抽出，永远与页面一致。
  3. LTspice 菜单 File → Open 选该 .cir，点工具栏「Run」（小人图标）。
  4. 波形窗口 Plot Settings → Add Trace（或右键）选 V(out) 等节点；.op 的结果在 View → SPICE Error Log 里，不弹波形窗。
  5. 网表里的注释一律用 ASCII 英文，避免 LTspice 对中文编码的兼容问题；中文解释全部写在页面正文。
  6. 部分实验为方便对照，同一网表里写了 .op + .tran + .ac 多条分析指令。只想看某一类波形时，把其余分析行行首加 * 注释掉再 Run。
给计算机专业学生的提示

SPICE 网表就是一门声明式"电路语言"：元件是对象、节点是变量、.tran/.ac/.dc 是求解器、.step/.meas 是循环与断言。你已有的编程直觉（抽象、模块化、测试、参数扫描）在这里全部有用。第 21 章会把它系统化成一套"仿真即测试"的方法；PyLTSpice 可以直接用 Python 批量跑这些网表。

学习路线（建议两个学期）

  1. 阶段 A · 让电路"能算"（卷首 + 第 3、4 章）：装好 LTspice，掌握 KCL/KVL、分压、戴维南等效、阻抗与一阶暂态。目标：随便给一张只有电阻和电容的图，能标出所有节点电压。
  2. 阶段 B · 认识有源器件（第 5～8 章）：二极管、MOSFET、BJT、理想运放。每个器件都问同一个问题：直流怎么偏置？小信号增益怎么算？阻抗是多少？目标：能画出小信号等效电路。
  3. 阶段 C · 拆解标准模块（第 9～18 章）：单级放大、电流镜、差分对、频响、反馈、运放、滤波器、比较器、电源、噪声。这是工业界与教材共用的"模块词汇表"，也是读数据手册（datasheet）里框图的语言。
  4. 阶段 D · 方法论与综合（第 19～24 章）：先学读（十步法解剖陌生电路），再学设计（从规格反推参数），最后用仿真验证、蒙特卡洛、误差预算与实测收尾，完成一个完整信号链课程设计。

如果时间有限，最短路径是：01 → 02 → 03 → 08 → 19 → 20 → 21。这几章构成"读懂 + 设计 + 验证"的最小闭环，其余章节按需回查。

推荐纸质教材（与本书章节的对应）

  • 入门主干：Sedra & Smith《Microelectronic Circuits》；康华光《电子技术基础（模拟部分）》；童诗白、华成英《模拟电子技术基础》——对应第一、二篇。
  • 工程直觉：Horowitz & Hill《The Art of Electronics》——对应第 8、16、17、23 章，最像"工程师怎么想"。
  • 集成电路方向：Razavi《Design of Analog CMOS Integrated Circuits》《Fundamentals of Microelectronics》；Gray & Meyer《Analysis and Design of Analog Integrated Circuits》；Allen & Holberg《CMOS Analog Circuit Design》——对应第 9～14 章。
  • 仿真与流程：Baker《CMOS: Circuit Design, Layout, and Simulation》；ADI《Op Amp Applications Handbook》《Linear Circuit Design Handbook》与《Analog Dialogue》——对应第三篇。

后续如何补充与完善

动作做法
细化某章在 tools/book_expansion.py 对应章节的 EXTRA_SECTIONS 里追加小节（再运行 python3 tools/build_book.py --force 重建）；也可以直接编辑该章 index.html，默认生成不会覆盖已有文件。
加扩展链接在 tools/book_resources.py 的 R 登记资源、TOPIC_RULES 加知识点关键词规则、CHAPTER_RESOURCES 调整该章默认资源，重建后自动出现在知识点地图与扩展学习小节。
加一个仿真实验在页面里新增 <pre class="spice" data-file="sim/xxx.cir"><code>…</code></pre>，然后运行 python3 tools/extract_netlists.py 自动生成 .cir。
加一节 / 加一章先在本页目录里加链接与知识点标签，再建文件夹与 index.html，最后在 assets/toc.js 追加一项（侧栏、上一章/下一章会自动更新）。
加入新参考资料在上方「参考资源」里按同样格式追加 .resource 卡片，注明仓库用途、许可证与核实时间。
自检运行 python3 tools/check_book.py，检查目录链接、toc.js 一致性、代码块与 .cir 的对应关系和 SPICE 基本语法。

目录、侧栏、上下章导航共用 assets/toc.js；样式集中在 assets/style.css；交互集中在 assets/app.js。全书无外部依赖，离线可用，也适合用 GitHub Pages 直接发布。

§22.1核心概念速览

  • PVT：Process（工艺角 TT/FF/SS/FS/SF）、Voltage（电源 ±10%）、Temperature（−40/25/125 ℃）；集成电路还要角 + 蒙特卡洛两套检查。
  • LTspice 内置 mc(x,tol)（均匀随机）、gauss(x)（正态随机），配合 .step param run 1 N 1 让每个元件独立抖动。
  • 最坏情况把所有参数同时取极限，保守但组合数爆炸；蒙特卡洛给分布与良率，更接近量产。
  • 灵敏度分析：一次只改一个参数，找出对输出影响最大的那一两项，把预算花在它们身上。
  • 规格必须留裕量：典型值居中、公差带内不越界，才算通过。

§22.2PVT 与工艺角

典型条件（TT、25 ℃、标称电源）下的漂亮曲线只是起点。批量生产要面对三组变化：

维度常见取值主要影响
Process（工艺角）TT / FF / SS / FS / SF（NMOS 与 PMOS 快、慢组合）Vto、迁移率、增益、带宽
Voltage标称 ±10%摆幅、静态点、压摆率
Temperature−40 / 25 / 125 ℃VBE、Vto、迁移率、漏电流

穷举全部组合（5 × 3 × 3 = 45 个角）常用脚本批量跑：PyLTSpice 可以用 Python 循环改 .param、调用 LTspice 命令行、解析 .log 里的 .meas 结果，自动生成一张通过/失败表。

§22.3蒙特卡洛：从单次仿真到分布

工艺角描述的是全局偏差（整片晶圆一起偏），蒙特卡洛描述的是局部失配（同一芯片上两个本应相同的器件不一样）。LTspice 提供：

  • mc(x, tol)：在 x·(1±tol) 内均匀分布随机取值；
  • gauss(x)：正态分布的随机偏移；
  • .step param run 1 N 1：让每次运行取一组新随机数（N 常取 50～1000）。

实验 22-1 里 R1 取 1%、R2 取 5%，输出分布明显由 R2 主导。把 N 组 .meas 结果导出成 CSV，用 Python 算均值、σ、画直方图，就能回答「良率多少」而不是「这次对不对」。

常见错误：多个元件共用同一个随机表达式，导致它们的误差完全相关，仿真结果远比现实乐观。每个元件应有独立的 mc() 调用。

§22.4灵敏度、最坏情况与裕量

  1. 灵敏度分析：一次只改一个参数 ±10%，记录输出变化，按影响大小排序；预算只花在前几项上。
  2. 最坏情况（WCA）：把每个参数取对规格最不利的端点同时组合。它对线性单调系统很保守、组合数按 2ⁿ 增长；PyLTSpice 的 WorstCaseAnalysis 用位编码自动枚举这些组合。
  3. 蒙特卡洛：给分布与良率，更接近量产，但不能证明「极端情况也过」。
  4. 裕量：规格不是目标值而是边界。典型条件下让增益、带宽、相位裕度、摆幅各留 10%～20%（相位裕度留 45°～60°），公差带内才不会越界。

三者的关系：灵敏度找主因 → 最坏情况保底线 → 蒙特卡洛估良率。只做其中一个，都不足以支撑「可以投产」的结论。

§22.5把鲁棒性写进验收表

在第 20 章的验收表基础上，把每个指标扩成三列：典型值 / 最坏情况 / 蒙特卡洛 3σ。例如增益一行：10.00 / 9.88～10.12 / σ = 0.02。再加一条明确的判据（如「全部条件下误差不超过 2%」）。

这样仿真就从「画几条曲线」升级成可重复的回归测试：以后改任何一个参数，跑一次脚本就知道是否仍然通过。第 21 章的 .meas 断言是这套流程的基础。

§仿真实验

实验 22-1：分压器公差的 50 次蒙特卡洛

* Ch22 Monte-Carlo of resistor tolerances
.param run=1
.param R1v=mc(10k,0.01)
.param R2v=mc(10k,0.05)
V1 in 0 DC 5
R1 in out {R1v}
R2 out 0 {R2v}
.step param run 1 50 1
.op
.meas OP vout FIND V(out)
.end

操作：Run → Error Log 读出 50 个 vout；把数据粘进表格或 Python 画直方图。　预期与判读：标称 2.500 V；R2 的 5% 公差主导输出离散，分布宽度约 ±0.06 V 量级。把 R2 公差改成 1% 再跑一次，对比 σ 的变化。　文件位置：part3/22-robustness/sim/22-monte-carlo.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 只跑一次典型仿真就下结论。
  • 把 mc() 的结果当成“最坏情况”：统计不等于边界。
  • 所有元件用同一个随机数，导致误差被错误地相关化。

§习题与思考

  1. 给 V1 加 ±5% 公差，观察分布如何平移。
  2. 设计一组最坏情况（R1 最大 / R2 最小等），与蒙特卡洛极值比较。

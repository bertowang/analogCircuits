§22.1核心概念速览

  • PVT：Process（工艺角 TT/FF/SS/FS/SF）、Voltage（电源 ±10%）、Temperature（−40/25/125 ℃）；集成电路还要角 + 蒙特卡洛两套检查。
  • LTspice 内置 mc(x,tol)（均匀随机）、gauss(x)（正态随机），配合 .step param run 1 N 1 让每个元件独立抖动。
  • 最坏情况把所有参数同时取极限，保守但组合数爆炸；蒙特卡洛给分布与良率，更接近量产。
  • 灵敏度分析：一次只改一个参数，找出对输出影响最大的那一两项，把预算花在它们身上。
  • 规格必须留裕量：典型值居中、公差带内不越界，才算通过。

§仿真实验

实验 22-1：分压器公差的 50 次蒙特卡洛

* Ch22 Monte-Carlo of resistor tolerances
.param run=1
.param R1v=mc(10k,0.01)
.param R2v=mc(10k,0.05)
V1 in 0 DC 5
R1 in out {R1v}
R2 out 0 {R2v}
.step param run 1 50 1
.op
.meas OP vout FIND V(out)
.end

操作：Run → Error Log 读出 50 个 vout；把数据粘进表格或 Python 画直方图。　预期与判读：标称 2.500 V；R2 的 5% 公差主导输出离散，分布宽度约 ±0.06 V 量级。把 R2 公差改成 1% 再跑一次，对比 σ 的变化。　文件位置：part3/22-robustness/sim/22-monte-carlo.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 只跑一次典型仿真就下结论。
  • 把 mc() 的结果当成“最坏情况”：统计不等于边界。
  • 所有元件用同一个随机数，导致误差被错误地相关化。

§习题与思考

  1. 给 V1 加 ±5% 公差，观察分布如何平移。
  2. 设计一组最坏情况（R1 最大 / R2 最小等），与蒙特卡洛极值比较。

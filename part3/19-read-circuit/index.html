§19.1为什么“看懂”这么难

一张模拟电路图上，至少叠了四层信息，而它们共用同一批线条：

  1. 直流供电与偏置：谁给谁提供电流，静态工作点在哪；
  2. 信号通路：输入从哪进来、经过几级增益、从哪出去；
  3. 反馈环路：哪条线把输出又送回输入，是正还是负；
  4. 辅助与保护：启动电路、补偿电容、去耦、限流、ESD、关断控制。

新手常犯的错是“顺着线从头看到尾”，结果在电源线和反馈线之间迷路。正确做法是按层分块，一次只看一层。下面十步就是固定的分层顺序。

§19.2十步拆解法

步动作要写下的产物
1圈出所有电源、地、参考电位，标出电源范围电源树：VDD / VSS / VREF 各接到哪些模块
2找输入端与输出端（最左/最右、接插件名、芯片引脚名）信号流方向的粗箭头
3按“功能块”切图：偏置、输入级、增益级、输出级、反馈网络、保护方框草图，每块一句话说明功能
4画直流通路：电容开路、电感短路、交流源置零直流等效图 + 各节点电位数量级
5画交流小信号通路：电源接交流地、大电容短路、器件换小信号模型小信号等效图 + 增益表达式
6找所有环路，逐个判正负（沿环走一圈数反相次数）环路清单：主负反馈 / 局部反馈 / 正反馈 / 启动环
7识别辅助支路：启动、补偿、去耦、限流、保护、修调每个“看不懂的元件”给出存在理由
8做数量级估算：电流、gm、增益、带宽、摆幅一张手算表（不追求精确，只求量级对）
9用 .op 反查假设：每个管子的工作区、Id、gm、Vov假设 vs 实测对照，标出矛盾处
10用 .tran / .ac 回答“它到底做什么"功能结论一句话 + 关键波形
可打印检查单

电源地 → 输入输出 → 分块 → 直流图 → 交流图 → 环路正负 → 辅助支路 → 数量级 → .op 反查 → 波形结论。做完十步仍读不懂，通常不是能力问题，而是缺前置知识：回到第一、二篇查对应模块。

§19.4标注法：把图“重写”一遍

不要在原图上冥思苦想，动手重画一遍，并用三种标记分层：

  • 给每个节点起名字（bias、tail、dn、dp），名字本身带上功能信息；
  • 用一种颜色/线型画直流电流路径（VDD → 负载 → 管子 → 尾电流源 → VSS），另一种画信号路径（输入 → 差分对 → 增益级 → 输出）；
  • 把反馈环单独画成箭头闭环，并在旁边写“负（1 次反相）”或“正”。

本书所有网表都用功能化节点名，就是为了和这个习惯对齐。读别人的 .asc 原理图时，第一步也应是把 N001 之类改成有意义的标签。

§19.5数量级估算：先粗后细

在打开仿真器之前，先做 60 秒估算，能挡掉绝大部分理解错误：

  • 电源 5 V、电阻 kΩ 级 ⇒ 电流约 mA 级；电流镜 µA 级 ⇒ 电阻一般 MΩ 或管子很小。
  • MOS 过驱动 Vov 常取 0.1～0.3 V；gm = 2ID/Vov ⇒ 100 µA 对应约 1 mS。
  • 单级增益 gm·Rout 常在 5～50；两级 100～10000；主极点常在 kΩ × pF = ns～µs 量级。
  • 摆幅预算：电源电压减去各管所需的最小 VDS，通常每只管子留 0.2～0.3 V。

估出来的数如果和仿真差 10 倍以上，几乎一定是工作区假设错了，而不是模型不准。

§19.6用 .op 反查假设

.op 的输出里，对每个 MOS 会列出 Id、Vgs、Vds、Vth、Vov、gm、ro 与工作区。检查顺序：

  1. Vov > 0 且 Vds ≥ Vov ⇒ 饱和（放大区）。若不满足，直流假设要重来。
  2. 各支路电流是否满足 KCL？尾电流是否等于两支路之和？镜像比例对不对？
  3. 静态输出电压是否落在预期摆幅中间？给正负信号各留了多少余量？
  4. gm 是否与 2Id/Vov 一致？不一致说明模型比你用的公式复杂（这是好事，记下来）。

§19.7完整案例：五管 OTA 单位增益跟随器

下方实验 19-1 是一个“看起来陌生”的电路：2 个电源、1 路偏置、4 只镜子/差分管、1 只输出管，还把输出接回了输入。按十步法走一遍：

  1. 电源/地：VDD = +2.5 V、VSS = −2.5 V，地是信号参考，不是电源中点。
  2. 输入输出：VIN 接 inp；输出取 dp；VFB（0 V 源）把 dp 短接到 inn，因此是单位增益反馈。
  3. 分块：IB + MB 是偏置基准；MT 是尾电流镜（W 翻倍 ⇒ 100 µA）；M1/M2 是差分对；M3/M4 是 PMOS 电流镜负载；输出在 dp。
  4. 直流通路：IB(50 µA) → MB → VSS；MT 复制出 100 µA 尾电流；差分对平衡时各 50 µA；M3 二极管连接产生约 1.68 V 的栅压，M4 复制 50 µA。
  5. 交流通路：VDD/VSS 是交流地；差分对把 v(inp)−v(inn) 变成漏极电流差，电流镜把两路差合并到 dp，等效跨导约 gm；输出阻抗 = ro2∥ro4。
  6. 环路：dp → inn 只有一条。沿环走：输入升高 → M1 电流增 → dn 降 → M4 电流增 → dp 升 → inn 升 → M2 电流增，抵消原变化，故为负反馈。
  7. 辅助支路：VFB 是 0 V 源，用于把两根线连起来并顺便测电流，不是放大器；本例未画补偿电容（单级、高输出阻抗，实际集成电路需要）。
  8. 估算：每支路 50 µA，Vov ≈ 0.16 V，gm ≈ 0.6 mS，ro ≈ 1/(0.02×50µ) = 1 MΩ ⇒ 开环增益约 gm(ro/2) ≈ 300。闭环增益 ≈ 1。
  9. .op 反查：检查 M1～M4 是否都在饱和区、dp 是否接近 0 V、IB/MT 电流比是否 1:2。
  10. 结论：这是一个五管 OTA 构成的电压跟随器，用高开环增益换取精确的单位增益缓冲。

把 VIN 的 DC 改成 0.5 V，输出也会跟到约 0.5 V——这就是“读懂了”之后能做出的预测。能预测，才算真懂。

§常见误区

  • 顺着线从头看到尾，没有先分层分块。
  • 把反馈线当成信号线，或漏掉局部反馈环。
  • 看到不认识的元件就跳过：启动、补偿、去耦往往正是理解设计意图的钥匙。
  • 直接跑仿真看波形，跳过手算与 .op，得到“看起来合理”却解释不通的结论。

§习题与思考

  1. 把 VIN 的 DC 改成 0.5 V，先预测 V(dp)，再仿真核对。
  2. 删掉 VFB（把 dp 与 inn 断开并给 inn 接固定 2 V），说明电路变成什么、输出会怎样。
  3. 把 MT 的 W 改成 40u，预测尾电流、gm 与开环增益的变化。
  4. 找一张数据手册里的框图（如运放、LDO），用十步法写一份不超过一页的阅读笔记。

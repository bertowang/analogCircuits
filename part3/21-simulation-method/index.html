§21.1先问问题，再选分析

我想知道用别误用
偏置对不对、管子在哪个区.op不要靠 .tran 的起始段猜
输入变化时的非线性传输关系.dc不要用于含电容的动态过程
增益、带宽、相位、阻抗随频率.ac不能看失真、饱和、压摆
波形、摆幅、失真、启动、振荡.tran不能用小信号线性化替代
噪声、THD、稳定性.noise / .four + 环路分析THD 需要足够长且稳定的时间窗

§21.2测试台：把被测电路和测量仪器分开

  1. 激励：小信号用 AC 1，瞬态用 PULSE/SINE 并给有限边沿；源阻抗要显式写出（理想源常被误当成零阻抗）。
  2. 负载：把后级输入阻抗、探头电容都画进去（见第 23 章）。
  3. 隔离：用跟随器或大电阻把“测量”与“被测”隔开，避免测试电路改变工作点。
  4. 探针：给关键节点起名字，只保存需要的量（.save）可大幅缩小 .raw。
  5. 基准：先用最简单的理想电路跑一遍，确认测试台本身没写错，再换成真实模型。

§21.3.meas 就是断言

把“眼睛看曲线”换成“数字过阈值”：增益、−3 dB 频率、上升时间、过冲、功耗、静态误差都能写成 .meas，结果进 Error Log，可被脚本解析。配合 .step 就是参数化的回归测试。

.meas TRAN trise TRIG V(out) VAL=0.1 RISE=1 TARG V(out) VAL=0.9 RISE=1
.meas TRAN vfinal FIND V(out) AT 4m
.meas AC gain1k FIND mag(V(out)) AT 1k

语法片段（非完整网表），可直接粘进实验 21-1。

§21.4八个“看起来对其实错”的陷阱

  1. 用理想源：没有内阻、没有噪声、没有寄生，结果天生过于漂亮。
  2. 忘了模型边界：Level-1 MOS 不含短沟道效应；运放宏模型可能不含压摆或输入共模限制。
  3. AC 分析掩盖非线性：.ac 把电路在工作点线性化，饱和、削顶、交越失真一律看不见。
  4. 波形压缩：默认压缩会让 FFT 出现虚假杂散，做频谱前写 .options plotwinsize=0。
  5. 时间窗太短 / 步长太大：THD、启动过程、慢极点都需要足够长的稳态窗口。
  6. 初始条件：振荡器或双稳态电路可能停在零解，需要 .ic 或噪声扰动（见第 16 章）。
  7. 收敛失败被“修好"：把容差放宽到能跑，往往是掩盖了悬浮节点或理想开关。
  8. 单位与量纲：m 与 Meg、dB 与倍数、峰值与 RMS，每年都坑人。

§21.5仿真 ≠ 实测：差异清单

仿真里没有（或过于理想）实测中会出现对策
PCB 走线电阻/电感、过孔、寄生电容高频增益偏差、振铃加估计寄生参数再仿真
元件公差与温漂批量个体差异蒙特卡洛 / 最坏情况（第 22 章）
电源内阻、地线阻抗、去耦不足低频振荡、串扰显式建电源与地网络
探头负载、仪器带宽被测点被探头改变把探头模型放进测试台（第 23 章）
器件老化、ESD 损伤、焊接问题无法复现的异常分模块上电、故障树排除

结论应当是条件式的：“在这些模型与假设下，增益为 10、带宽 1.4 MHz"，而不是无条件的“增益就是 10”。

§21.6实验记录模板

每次仿真写六行：目的 / 测试台（激励·负载·模型） / 手算预期 / 仿真实测 / 偏差原因 / 下一步改哪个参数。积累起来的记录，比任何一张波形截图都值钱。

§仿真实验

实验 21-1：带自动测量的 RC 测试台

* Ch21 Testbench: parameter sweep with .meas assertions
.param R=1k
VIN in 0 PULSE(0 1 0 1n 1n 2m 4m)
R1 in out {R}
C1 out 0 100n
.step param R list 1k 2k 5k
.tran 0 5m 0 1u
.meas TRAN trise TRIG V(out) VAL=0.1 RISE=1 TARG V(out) VAL=0.9 RISE=1
.meas TRAN vfinal FIND V(out) AT 4m
.end

操作：Run → Error Log 读 3 组 trise / vfinal；把结果与 2.2·R·C 手算值对照。　预期与判读：10%→90% 上升时间 = 2.2RC：R=1k/2k/5k 时约 220 µs / 440 µs / 1.1 ms；终值均为 1 V。　文件位置：part3/21-simulation-method/sim/21-testbench-meas.cir

实验 21-2：正确的频谱分析设置

* Ch21 FFT setup: disable waveform compression
VIN in 0 SINE(0 1 1k)
R1 in out 1k
C1 out 0 100n
.tran 0 20m 0 2u
.four 1k V(out)
.options plotwinsize=0
.end

操作：Run → Error Log 读 Fourier 结果；波形窗口右键 → View → FFT 交互查看。　预期与判读：1 kHz 基波被 RC 低通衰减约 0.85 倍并相移；删掉 .options 行后再做 FFT，可观察到压缩对频谱底噪的影响。　文件位置：part3/21-simulation-method/sim/21-fft-setup.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 只会用 .tran 一种分析看所有问题。
  • 测试台里的理想电压源直接并到电容上，导致不收敛或 unrealistic 结果。
  • 仿真结果和手算差 10 倍仍照单全收。
  • 把仿真结论写成无条件事实，没有标注模型与假设。

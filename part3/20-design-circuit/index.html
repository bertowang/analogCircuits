§20.1规格先于拓扑

新手最先问“用哪个电路”，工程师最先问“要满足什么”。一份可验收的规格至少包含：

类别要写清的条目例子
信号源阻抗、幅度范围、频率范围、共模电平10 kΩ 源，±0.5 V，10 Hz～100 kHz
增益 / 精度标称增益、误差、线性度、失调−10 V/V，误差 ≤ 2%
频域带宽、相位裕度、噪声、滤波要求−3 dB ≥ 200 kHz
负载 / 电源负载阻抗、可用电源、功耗上限10 kΩ ∥ 10 pF，±5 V，≤ 20 mW
环境温度范围、器件公差、批量一致性0～70 ℃，电阻 1%
验收怎么测、测哪几个点、判据1 kHz 增益、100 kHz 增益、阶跃过冲

没有验收方法的规格等于没有规格。写规格时就要想好后面 .meas 测什么。

§20.2指标分解树与选型矩阵

把总指标拆到每个模块头上，让每个模块只承担一两项要求：

总指标: |Av|=10, BW>=200kHz, 误差<=2%, Rin>=10k
  ├─ 输入级/电阻网络: Rin, 噪声增益, 电阻比精度
  ├─ 放大核心: 开环增益 A0, GBW, 相位裕度
  └─ 输出级: 摆幅, 负载驱动, 功耗

上面是分解示意（非网表）。

需求候选拓扑选择理由
高输入阻抗、同相同相运放 / 仪表放大输入不取电流
增益由电阻比精确决定、可求和反相运放虚地使增益 ≈ −Rf/Rin
单电源、微弱差分信号仪表放大器 / 差分 ADC 驱动共模抑制与电平搬移
极低功耗、单片集成OTA / 两级 CMOS 运放可自主分配电流与补偿

选型的本质是取舍：增益、带宽、噪声、功耗、面积、成本不可能同时最优。把选与不选的理由写下来，比选型结果本身更重要。

§20.3手算定参数：一个完整案例

规格：反相放大器，增益 −10 V/V，带宽 ≥ 200 kHz，输入电阻 ≥ 10 kΩ，信号 ±0.5 V，电源 ±5 V（行为级模型）。

  1. 定电阻：Rin = 10 kΩ ⇒ Rf = 100 kΩ。噪声增益 NG = 1 + Rf/Rin = 11。
  2. 定运放带宽：闭环带宽 ≈ GBW/NG，故 GBW ≥ 200 k × 11 = 2.2 MHz。自建模型的 A0 = 1e5、主极点 159 Hz ⇒ GBW ≈ 15.9 MHz，裕量充足。
  3. 校核精度：有限开环增益带来的相对误差 ≈ NG/A0 = 11/1e5 = 0.011%，远小于 2%；主要误差来自电阻公差，用 0.1% 电阻即可。
  4. 校核摆幅：输出峰值 = 10 × 0.5 = 5 V，正好贴住电源轨 ⇒ 规格冲突，必须把电源提高到 ±7 V 或把增益需求下调。这一步正是手算的价值：仿真会给你一条“看起来没问题”的波形，而规格审查提前发现了问题。
  5. 定验收点：1 kHz 增益、100 kHz 增益、1 MHz 增益、阶跃过冲；写成 .meas 断言。

§20.4把验收写成自动化脚本

实验 20-1 用 .step param RFv 一次跑三组候选值，用 .meas AC ... FIND mag(V(oa)) AT 频率 把验收结果写成数字。这就是模拟电路里的回归测试：以后每次改参数，跑一次脚本，看数字是否仍在规格内。

把这一步接到 PyLTSpice 上，可以用 Python 循环上百组参数、读取 .log 里的 .meas 结果、自动画趋势图。对计算机专业学生，这是最容易发挥既有优势的地方。

§20.5公差、裕量与文档

  • 公差：电阻 1%、电容 10%、Vos、温漂；按第 22 章方法做蒙特卡洛。
  • 裕量：环路增益留 10 倍、相位裕度留 45°～60°、摆幅留 10%～20%、功耗留 20%。没有裕量的设计只在典型条件下成立。
  • 设计文档模板：规格表 → 分解树 → 选型与理由 → 手算过程 → 原理图/网表 → 仿真验收表（目标/实测/通过）→ 公差与最坏情况 → 遗留风险 → 实测计划。

§仿真实验

实验 20-1：候选参数扫描 + 自动验收

* Ch20 Design verification: inverting amplifier, target gain -10
.param RFv=100k
VIN in 0 DC 0 AC 1
RG in minus 10k
RF oa minus {RFv}
E1 int 0 0 minus 1e5
R1 int oa 1k
C1 oa 0 1u
.step param RFv list 50k 100k 150k
.ac dec 20 10 10Meg
.meas AC gain1k FIND mag(V(oa)) AT 1k
.meas AC gain100k FIND mag(V(oa)) AT 100k
.meas AC gain1meg FIND mag(V(oa)) AT 1Meg
.end

操作：Run → View → SPICE Error Log，把 3 组 × 3 个频点的结果填进验收表。　预期与判读：RFv = 100k 时 1 kHz 增益 ≈ 10（20 dB），100 kHz 仍接近 10，1 MHz 开始滚降（GBW/NG ≈ 1.45 MHz）；RFv = 50k / 150k 分别得到约 5 / 15。只有 100k 满足规格。　文件位置：part3/20-design-circuit/sim/20-design-verification.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 先选电路再补规格，导致做出来不知道算不算成功。
  • 只验证典型条件，没做公差、温度、电源变化。
  • 规格之间互相冲突却在最后才发现（例如增益 × 输入幅度超出电源轨）。
  • 把仿真波形截图当验收证据，没有可复现的数字断言。

§习题与思考

  1. 把规格改成增益 −5、输入 ±1 V，重新走一遍五步并修改网表。
  2. 给 RG、RF 各加 1% 公差，用 .step 估计增益的最坏偏差。
  3. 补一条 .meas 测量 100 kHz 处的相位，解释它为何影响稳定性。

§0.1三类变量，三种视图

同一张电路图，其实叠了三层信息。读图出错，大多是因为把三层混在一起：

视图符号习惯关心什么对应仿真
直流 / 静态工作点大写大写下标，如 VGS、ID偏置是否成立、器件在哪个工作区.op / .dc
交流小信号小写，如 vgs、id增益、阻抗、频率响应、噪声.ac / .noise
大信号 / 瞬态总量小写大写下标，如 vGS(t)摆幅、失真、启动、饱和、压摆.tran

读图口诀：先用直流视图确认每个器件“活着”（有正确偏置、在正确工作区），再切到小信号视图算增益与阻抗，最后用瞬态视图检查摆幅和失真。

§0.2固定要问的四个问题

后面每一章、每一个电路，都问同样四个问题，答案会自然形成笔记：

  1. 直流怎么偏置？电源到地有没有直流通路？每个节点的静态电压大约多少？
  2. 小信号增益怎么算？控制量是什么（vbe / vgs）？跨导 gm 多大？负载阻抗多大？
  3. 输入、输出阻抗是多少？前一级会不会被拖垮？后一级会不会成为负载？
  4. 带宽与摆幅边界在哪？哪个电容形成主极点？输出最高/最低能到多少？

§0.3手算与仿真的分工

仿真是验证工具，不是推导工具。手算给出数量级和趋势，仿真给出精确数值与非理想效应，两者不一致时先怀疑自己的模型假设，而不是先怀疑软件。

推荐记录格式：手算预期值 → 仿真实测值 → 偏差百分比 → 偏差原因。写满 20 组这样的记录，读电路的能力会有明显变化。

§0.4符号、单位与绘图约定

模拟电路的符号混乱是初学者的第一道坎，本书统一如下：

写法含义例子
VGS、ID直流总量 / 静态工作点ID = 1 mA
vgs、id交流小信号量id = gmvgs
vGS(t)含直流偏置的瞬时总量vGS(t) = VGS + vgs(t)
V(s)、H(s)s 域 / 频域复数量H(s) = 1/(1+sRC)

其他约定：电流箭头默认指正电荷方向；算出负值说明实际方向相反，不必改方程。电压下标 Vab 表示 a 点相对 b 点。参考地符号只表示人为选定的零电位，不等同于大地或机壳。工程记数法见附录 A.2，特别注意 m 与 Meg。

画图规范：电源在上、地在下，信号从左到右，反馈画出清晰的闭环，节点起有意义的名字。规范不只是好看——它直接决定别人（以及三个月后的你）能不能读懂这张图，参见第 19 章。

§0.5先修知识与学习节奏

本书只需要四块数学工具，缺哪块补哪块即可，不必先修完一整门课：

  1. 线性方程组：节点电压法就是列 KCL 方程组（第 3 章）。
  2. 复数与相量：阻抗 Z = R + jX、幅角与模，用于 .ac 分析（第 4 章）。
  3. 一阶常微分方程：RC/RL 充放电的指数解 e−t/τ；会用三要素法就不用每次解微分方程。
  4. 拉普拉斯变换的结论：只要知道「电容 → 1/sC、电感 → sL」以及极零点与波特图的对应关系就够用；严格推导可留到信号与系统课。

建议节奏：每章 2～3 学时，其中手算 1/3、仿真 1/3、改参数与记录 1/3。做完每章的四步闭环（手算 → 仿真 → 改参数 → 写结论）比多看三章但不做实验有效得多。

§0.6教材、数据手册与仿真：三种语言

同一个电路，在三种场合有三种写法，学会互相翻译才算入门：

场合表达方式关注点
教材小信号等效电路 + 符号推导因果、趋势、可迁移的结论
数据手册 / 应用笔记框图、参数表、典型应用电路边界条件、裕量、外围元件怎么选
SPICE 网表元件 + 节点 + 模型 + 分析指令可执行的精确数值、非理想效应

工业界的常见顺序是：先用教材公式圈定拓扑，再查数据手册确认边界，最后用仿真验证并留出裕量；反过来「先跑仿真再解释」很容易得出只在该模型下成立的结论。第 20 章与第 21 章会把这个顺序固化成流程。

§仿真实验

最小完整网表：分压器

* Ch00 Minimal netlist: a voltage divider
V1 in 0 DC 5
R1 in out 3k
R2 out 0 2k
.op
.end

操作：保存为 .cir → LTspice 打开 → Run → View → SPICE Error Log 查看 V(out)。　预期与判读：手算 V(out) = 5 × 2k/(3k+2k) = 2.000 V，电流 1 mA。　文件位置：part0/00-preface/sim/00-minimal.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 把 m 当成兆：SPICE 里 m = 毫，1Meg = 兆。
  • 只看波形不看工作点：偏置错了，波形也可能“看起来有形状”。

§习题与思考

  1. 把 R2 改成 2k 的 1% 公差，估计 V(out) 的变化范围。
  2. 在分压器输出端接 1k 负载，重算 V(out)，再用仿真核对。

§2.1网表的五段结构

一个 .cir 文件只有五类内容，顺序固定：

  1. 标题行：第一行永远是标题，即使写成 * 注释也可以（不要在这里放元件）。
  2. 元件行：名字 + 节点 + 值/模型。元件名首字母决定类型。
  3. 模型 / 参数：.model、.param、.func。
  4. 分析与控制：.op、.tran、.ac、.dc、.step、.meas、.options。
  5. 结束：.end。

注释：整行以 * 开头，行内用 ;。节点名可以是数字或字符串，0（或 GND）是全局参考地。

§2.2元件行速查

首字母语法示例
R / C / L名字 节点+ 节点- 值R1 in out 10k
V / I名字 节点+ 节点- DC 值 AC 幅值 波形V1 in 0 DC 0 AC 1 SINE(0 1 1k)
D名字 阳极 阴极 模型名D1 a 0 DGEN
Q名字 C B E 模型名Q1 out base emit NPN1
M名字 D G S B 模型名 W= L=M1 d g 0 0 NM1 W=10u L=1u
E / G / F / H受控源，E名 输出+ 输出- 输入+ 输入- 增益E1 out 0 inp inn 1e5
B行为源，B名 节点+ 节点- V=表达式B1 out 0 V=max(0,V(in))

激励波形：SINE(Voffset Vamp Freq)、PULSE(V1 V2 Tdelay Trise Tfall Ton Tperiod)、EXP、PWL。

§2.3单位：最容易踩的坑

SPICE 大小写不敏感，m 是毫，Meg 才是兆：1m = 10⁻³，1u = 10⁻⁶，1n = 10⁻⁹，1p = 10⁻¹²，1f = 10⁻¹⁵，1k = 10³，1Meg = 10⁶，1G = 10⁹。写 1M 得到的仍是 1 毫。

网表里不要写单位字母（10k 而不是 10kΩ），不要写千分位逗号。

§2.4参数化：把仿真变成实验

.param 定义常量，元件值用花括号引用；.step 让同一个网表重复运行；.meas 把结果写成可比较的数字。三者合起来就是“带断言的参数化测试”：

.param Rtop=3k
R1 in out {Rtop}
.step param Rtop list 1k 2k 3k
.meas OP vout FIND V(out)

上面这段是语法片段，不是完整网表；完整可运行版本见下方实验 2-1。

.meas 的常用形式：.meas TRAN 名称 FIND V(x) AT 时间、.meas AC 名称 FIND mag(V(x)) AT 频率、.meas TRAN 名称 TRIG ... TARG ...（测延时/上升时间）。结果全部写进 Error Log，可以用脚本解析。

§2.5模型与层次化

.model 名称 类型(参数...) 定义器件模型，例如 .model NM1 NMOS(Vto=0.5 Kp=200u Lambda=0.02)。Level-1 MOS 模型参数少、行为可预测，特别适合教学；真实工艺模型（BSIM）有上百个参数，反而看不清物理含义。

真实项目里用 .lib 厂商库.lib 引入模型、.subckt / .ends 定义子电路、.include 包含文件、X1 ... 子电路名 实例化。本书为可移植性一律自包含，不用外部库。

§2.6收敛性速查

  1. 每个节点是否有到地的直流通路（必要时并联 1G 电阻）。
  2. 理想电压源是否被电容直接短路、两个理想电压源是否并联（加小串联电阻）。
  3. PULSE 边沿是否过陡（给有限 Trise/Tfall）。
  4. 先跑 .op 确认工作点，再跑 .tran。
  5. 最后才动 .options（gmin、abstol、reltol、maxstep）——改容差是掩盖问题，不是解决问题。

§仿真实验

实验 2-1：参数化分压器 + 扫描 + 自动测量

* Ch02 Netlist syntax: params, step and automatic measurements
.param Rtop=3k
V1 in 0 DC 5
R1 in out {Rtop}
R2 out 0 2k
.step param Rtop list 1k 2k 3k 4k
.op
.meas OP vout FIND V(out)
.meas OP ir1 FIND I(R1)
.end

操作：Run → View → SPICE Error Log，找到 4 组 vout / ir1 的测量值。　预期与判读：V(out) = 5×2k/(Rtop+2k)：Rtop = 1k/2k/3k/4k 时分别为 3.333 / 2.500 / 2.000 / 1.667 V。　文件位置：part0/02-spice-netlist/sim/02-param-divider.cir

实验 2-2：同一电路的 AC 与 DC 两种视图

* Ch02 AC source specification and a small-signal sweep
V1 in 0 DC 0 AC 1
R1 in out 1k
C1 out 0 100n
.ac dec 20 10 100k
.meas AC g10 FIND mag(V(out)) AT 10
.meas AC g1k FIND mag(V(out)) AT 1k
.end

操作：Run → Add Trace → V(out)，右键纵坐标可切到 dB 显示。　预期与判读：低频增益约 1（0 dB）；fc = 1/(2πRC) ≈ 1.59 kHz；1 kHz 处 |H| ≈ 0.846。　文件位置：part0/02-spice-netlist/sim/02-ac-source.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 用 1M 表示 1 兆：实际是 1 毫。
  • 把 .param 写在元件行之后才引用：LTspice 允许，但为可读性放在前面。
  • 网表里写中文注释或中文节点名：部分版本会报语法错。
  • 把原理图 .asc 当成文本网表直接改：.asc 有自己的语法，本书不涉及。

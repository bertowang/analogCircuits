§24.1三个课程设计课题

课题规格示例用到的章节验收方式
A. 传感器信号链桥式传感器 ±10 mV，输出 0～2 V，带宽 ≤ 100 Hz，共模抑制 ≥ 60 dB3、8、11、15、18、21、23.ac 增益与截止频率；.tran 阶跃响应；共模注入测 CMRR
B. 音频放大器8 Ω 负载 1 W，20 Hz～20 kHz，THD ≤ 1%8、13、16、17、18.four 测 THD；.tran 看削顶；功耗与热估算
C. 基准与 LDO输出 3.3 V，负载 0～100 mA，电源抑制 ≥ 40 dB5、10、13、17、22.dc 扫描输入/负载；温度扫描；蒙特卡洛

下方测试台是课题 A 的最小可运行版本：传感器等效源 → RC 抗混叠滤波 → 同相放大（增益 10）。按第 20 章的文档模板补齐规格、手算、验收表与公差分析，就是一个完整的大作业。

§24.2课题 A：传感器信号链（完整拆解）

规格：桥式传感器差分输出 ±10 mV、共模 1.25 V、源阻抗 1 kΩ；输出 0～2 V 单端；带宽 100 Hz；共模抑制 ≥ 60 dB；电源 3.3 V；总误差 ≤ 2%。

模块选型指标分配对应章节
前置放大仪表放大器 / 三运放结构增益 100，输入噪声 < 20 nV/√Hz11、18
电平搬移参考电压 + 差分/同相级把双极性信号移到 ADC 中点8
抗混叠滤波二阶 Butterworth 低通fc = 100 Hz，−40 dB/dec15
参考与电源基准 + LDO + 去耦PSRR 与纹波预算10、17

验收：用 .ac 测通带增益与 −3 dB 点；用 .tran 测阶跃建立；注入共模信号测 CMRR；用 .noise 积分得到输出噪声；最后按第 20 章写规格—实测评审表，并按第 22 章补公差分析。实验 24-1 是这条链的最小可运行版本。

§24.3课题 B / C 的关键难点

课题 B · 音频放大器（8 Ω、1 W、20 Hz～20 kHz、THD ≤ 1%）：

  • 输出功率换算：Vrms = √(PR) = 2.83 V，峰值 4 V，需检查电源与输出级摆幅；
  • 难点在交越失真与热：AB 类输出级偏置、负反馈降低 THD、.four 验收、功耗与散热估算；
  • 稳定性：容性负载（扬声器线缆）与输出级易自激，需做相位裕度检查。

课题 C · 基准与 LDO（3.3 V、0～100 mA、PSRR ≥ 40 dB）：

  • 难点在启动电路与温度系数：用 .dc 扫温度、.step 扫电源与负载；
  • 瞬态：负载阶跃的下冲幅度与恢复时间分别由输出电容和环路带宽决定，要分开优化；
  • 蒙特卡洛：带隙基准的失配直接决定输出电压分布，是本题最值得做的统计实验。

§24.4报告模板与验收清单

  1. 规格表：每条指标写清数值与测量方法。
  2. 指标分解树与选型理由：选了什么拓扑、放弃了什么、为什么。
  3. 手算过程：关键公式、参数、数量级校核。
  4. 原理图 / 网表：节点命名、模块标注、测试台与被测电路分开。
  5. 仿真验收表：目标值 / 实测值 / 通过与否 / 使用的分析指令。
  6. 公差与最坏情况：PVT、蒙特卡洛、裕量结论。
  7. 波形与判读：每张图配一句结论，不要只贴截图。
  8. 遗留风险与实测计划：哪些非理想尚未建模、上电时先测什么。

自测清单：所有 .cir 能直接 Run？.op 工作点合理？.meas 断言齐全？改一个参数后结论是否仍成立？把第 19 章十步法反过来用在自己的设计上，能独立讲清每一块的作用，就达到了本科课程设计的要求。

§仿真实验

实验 24-1：传感器信号链最小系统

* Ch24 Project A: sensor + anti-alias filter + gain of 10
VSENS sens 0 DC 0.1 AC 0.05 SINE(0.1 0.05 10)
RTH sens n1 1k
CF n1 0 1u
E1 int 0 n1 minus 1e5
R1 int oa 1k
C1 oa 0 1u
R2 oa minus 9k
R3 minus 0 1k
.op
.tran 0 500m 0 200u
.ac dec 20 1 100k
.meas AC gain10 FIND mag(V(oa)) AT 10
.end

操作：Run → .tran 看 10 Hz 信号被放大；.ac 看低频增益约 20 dB、高频被 CF 与运放主极点限制。　预期与判读：闭环增益 1 + 9k/1k = 10；CF 与 RTH 形成约 159 Hz 的低通；VSENS 的 50 mV 交流分量在输出约 0.5 V。　文件位置：part4/24-projects/sim/24-sensor-chain.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 课题一开始就画完整电路，没有先分模块定规格。
  • 只交仿真截图，没有验收表与设计文档。
  • 忽略模块之间的阻抗与电平匹配。

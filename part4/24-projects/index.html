§24.1三个课程设计课题

课题规格示例用到的章节验收方式
A. 传感器信号链桥式传感器 ±10 mV，输出 0～2 V，带宽 ≤ 100 Hz，共模抑制 ≥ 60 dB3、8、11、15、18、21、23.ac 增益与截止频率；.tran 阶跃响应；共模注入测 CMRR
B. 音频放大器8 Ω 负载 1 W，20 Hz～20 kHz，THD ≤ 1%8、13、16、17、18.four 测 THD；.tran 看削顶；功耗与热估算
C. 基准与 LDO输出 3.3 V，负载 0～100 mA，电源抑制 ≥ 40 dB5、10、13、17、22.dc 扫描输入/负载；温度扫描；蒙特卡洛

下方测试台是课题 A 的最小可运行版本：传感器等效源 → RC 抗混叠滤波 → 同相放大（增益 10）。按第 20 章的文档模板补齐规格、手算、验收表与公差分析，就是一个完整的大作业。

§仿真实验

实验 24-1：传感器信号链最小系统

* Ch24 Project A: sensor + anti-alias filter + gain of 10
VSENS sens 0 DC 0.1 AC 0.05 SINE(0.1 0.05 10)
RTH sens n1 1k
CF n1 0 1u
E1 int 0 n1 minus 1e5
R1 int oa 1k
C1 oa 0 1u
R2 oa minus 9k
R3 minus 0 1k
.op
.tran 0 500m 0 200u
.ac dec 20 1 100k
.meas AC gain10 FIND mag(V(oa)) AT 10
.end

操作：Run → .tran 看 10 Hz 信号被放大；.ac 看低频增益约 20 dB、高频被 CF 与运放主极点限制。　预期与判读：闭环增益 1 + 9k/1k = 10；CF 与 RTH 形成约 159 Hz 的低通；VSENS 的 50 mV 交流分量在输出约 0.5 V。　文件位置：part4/24-projects/sim/24-sensor-chain.cir

代码块右上角可一键复制；本仓库 sim/*.cir 由 tools/extract_netlists.py 从这些代码块自动抽取，因此页面与可运行网表永远一致。网表注释统一使用 ASCII 英文。

§常见误区

  • 课题一开始就画完整电路，没有先分模块定规格。
  • 只交仿真截图，没有验收表与设计文档。
  • 忽略模块之间的阻抗与电平匹配。
